# 06 VM 交付与部署

Magel 程序始终由共享 VM 执行。可以交付源码，也可以预先导出 `.svmb`，由桌面或目标宿主宿主加载。

## 源码运行

```sh
magel run app.mgl
```

编译器内嵌标准库和所需运行时资产；实际使用的操作系统、动态库、网络、数据库及外设仍由宿主提供。

## 字节码交付

```sh
magel svmb app.mgl out build/app
```

将 `.svmb`、`.data.bin`、`.layout` 和程序使用的资源交给目标宿主。VM 校验格式、特征位和数据布局，再绑定原生函数并执行。
`.quad` 是四元式中间产物，`emit` 可供检查或独立 VM 工具装配；它不是本机机器码。

宿主可以编译为本机可执行文件并嵌入字节码，执行仍通过 `stackvm::Machine`。Magel 不生成独立本机程序或 C 接口库。

## 资源与边界

宿主注册程序需要的胶水，设置数据区、堆、步数和输出接口，执行结束后检查错误及资源统计。
嵌入式 Linux 使用同一份 `library/stackvm/` 核心，宿主及胶水按目标架构构建，见[嵌入式 Linux 部署](book/25-嵌入式Linux部署.md)。

符号压缩用于缩减和隐藏符号名称，不构成加密、沙箱或防逆向保证。程序更新替换字节码，不自动迁移运行中的闭包、栈和全局状态。

详细接口见[宿主集成](08-host-integration.md)、[工具链](09-toolchain.md)和[SVMB 格式](15-svmb-format.md)。

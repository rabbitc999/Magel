# 编译器安全边界与定向回归

> 状态：下列修复已写入源码并完成解析器重新生成与编译器重建；定向回归与渗透测试在本机通过，渗透用例不再出现 UB / CRASH / TIMEOUT，只剩可被诊断的失败与正常输出。

本页记录已确认问题的保护行为和复现入口，不代表编译器不存在其他缺陷。

| 边界 | 处理 |
| --- | --- |
| 数据区整数超过 double 的精确范围 | 整数直接按 64 位解析，保留有符号最小值与 uint64 最大值的位模式 |
| 大浮点数导出为数据区浮点 | 不再无条件转换成 int64；先检查整数转换范围 |
| BigFloat 幂与方根的内部整数运算 | 先用除法检查指数范围，拒绝不可表示的精度；精度增长避免有符号溢出 |
| 拥有型 `?` 结果直接进入枚举构造器 | 构造参数接管表达式临时值时清空原拥有槽，避免重复清理 |
| 多个进程写同一个输出前缀 | 源码直接运行使用本次生成的内存数据映像；磁盘产物文件仍应使用不同前缀 |
| LP64、Clang 与 glibc | 避免 long/int64 构造重复、完整类型定义前实例化 JSON/TOML 成员、htons 宏与成员名冲突 |
| 独立 VM CMake 宿主依赖 | 明确包含 CAS、SQL 生成、SQLite 与压缩实现和对应 include/线程/动态库依赖 |
| 浮点转整数超出目标范围 | 运行期报「浮点转整数超出目标范围」；编译期常量折叠遇到越界不折叠，避免宿主上的未定义行为 |
| 十进制整数字面量超过 int64 | 编译期报「十进制整数超出 int64 范围」（此前静默饱和成 `INT64_MAX`）；`-9223372036854775808` 例外，幅值 2^63 由一元负号定型成最小值 |
| 浮点字面量溢出成 inf / NaN | 编译期报「浮点字面量超出可表示范围」（此前会串成「读未定义的变量：inf.0」） |
| JSON / TOML 嵌套层数 | 超过 256 层记为解析诊断（此前超深嵌套会把宿主栈打爆并崩溃） |
| 局部定长数组规模 | 编译期报「定长数组超出当前内存预算」（此前运行期 arena 耗尽后 `std::bad_alloc` 逃逸成 `terminate`），与 struct 字段的预算口径一致 |
| 定长数组维数连乘 | 统一走 64 位累加，溢出时夹到 int 上界（此前 `int` 连乘溢出后循环上界与槽偏移成错值） |
| 字符串切片负端点 | 运行期报「切片端点不能为负数（String 的切片按字节算）」（此前 `"abcdef"[0:-2]` 静默得到 `abcdef`）；`end == -1` 仍是内建 ABI 的「到末尾」约定 |
| 容器回调期间重入 | `vecFold` / `vecMap` / `vecFilter` 与谓词回调持引用迭代时上迭代器租约，回调里 `push` / `clear` 会被拒绝 |
| 遍历期间增删元素 | `push` / `set` 与 `remove` 同样受「活跃 for-in 引用期间不能移动或删除列表元素」保护 |
| `INT64_MIN / -1` | 运行期报「整数除法溢出：最小负数除以 -1 的结果超出 int64 范围」（此前静默给出 `-9223372036854775808`） |
| 移位位数超出位宽 | 运行期报「移位位数超出整数位宽（有效范围 0..63）」（此前 `& 63` 静默回绕，`1 << 64` 算成 `1`） |

定向回归：`python tests/chali_compiler_safety.py`。Linux 可用 `--cxx clang++ --sanitize-native` 对原生边界开启 ASan、UBSan 与浮点转整数检查；`--native-only` 只验证库边界。反射默认同时启用前端与运行时宏，VM 与四元式仍使用默认最高优化。

渗透测试：`python tests/chali_penetration.py`（`--only 子串` 可只跑部分用例）。它对数值转换、字面量、容器边界、所有权传播与规模预算构造攻击用例，把结果归类为 UB / CRASH / TIMEOUT / FAIL / OUTPUT，只收集事实、不做判定。

传播回归覆盖字符串成功、原始错误和容器载荷的重复清理。数据快照回归在优化转储阻塞时覆盖磁盘数据文件，检查当前 VM 执行不受影响。原生边界入口为 [chali_native_safety.cpp](../tests/chali_native_safety.cpp)。

大数运算仍受宿主内存与时间预算限制；这组保护不承诺任意巨大参数都能完成计算。发布时只报告实际执行的验证，未执行的跨平台或长期压力测试继续保留在任务验收记录中。

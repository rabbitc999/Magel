# 第 11 章 容器

前面几章你已经偷偷用过容器了——猜数字里没有，但从第 5 章的 `List<int64>`
开始就一直在用。这一章把它讲清楚。

Magel 内建三种容器，不用 `import`：

| 容器 | 装什么 | 什么时候用 |
| --- | --- | --- |
| `List<T>` | 有序的一串，按位置访问 | 顺序重要、要按下标取 |
| `Map<K, V>` | 键 → 值 | 按名字查东西 |
| `Set<T>` | 不重复的一堆，自动按升序 | 去重、判断「有没有」 |

---

## 11.1 `List<T>`：有序表

```magel
int64 main()
{
    List<int64> scores;
    scores.push(30);
    scores.push(10);
    scores.push(20);

    println("len={} at1={} has10={} idx={}",
        scores.len(), scores.at(1), scores.has(10), scores.indexOf(20));

    scores.insert(0, 7);
    println("insert 后：{} len={}", scores[0], scores.len());

    int64 last = scores.pop();
    println("pop={} len={}", last, scores.len());

    scores.remove(0);
    println("remove(0) 后：{} len={}", scores[0], scores.len());

    scores.clear();
    println("clear 后：len={}", scores.len());
    return 0;
}
```

```text
len=3 at1=10 has10=1 idx=2
insert 后：7 len=4
pop=20 len=3
remove(0) 后：30 len=2
clear 后：len=0
```

常用操作：

| 操作 | 作用 | 注意 |
| --- | --- | --- |
| `push(x)` | 在**末尾**加一个 | 最常用 |
| `insert(i, x)` | 在位置 `i` **插入** | 后面的元素整体后移 |
| `pop()` | 拿走**末尾**那个并返回 | 空表上调用会出错 |
| `remove(i)` | 删除位置 `i` | 按下标删，不是按值 |
| `clear()` | 清空 | |
| `len()` | 元素个数 | |
| `at(i)` / `list[i]` | 取位置 `i` | 两种写法等价 |
| `has(x)` | 有没有这个值 | 返回 `bool`（打印是 1/0） |
| `indexOf(x)` | 第一次出现在哪 | 没有时返回什么见下 |

**`indexOf` 找不到时返回 `-1`**——这是惯例，用的时候要判断：

<!-- no-run -->
```magel
int64 position = scores.indexOf(99);
if (position >= 0)
{
    println("在位置 {}", position);
}
else
{
    println("没有这个值");
}
```

## 11.2 `Map<K, V>`：键 → 值

```magel
int64 main()
{
    Map<String, int64> ages;
    ages.put("amy", 11);
    ages["cid"] = 33;

    println("len={} amy={} hasBob={} cid={}",
        ages.len(), ages["amy"], ages.has("bob"), ages["cid"]);

    println("查一个没有的键：{}", ages["zoe"]);

    for (int64 i = 0; i < ages.len(); i = i + 1)
    {
        println("{} -> {}", ages.keyAt(i), ages.valAt(i));
    }
    return 0;
}
```

```text
len=2 amy=11 hasBob=0 cid=33
查一个没有的键：0
amy -> 11
cid -> 33
```

写法：

- **`put(k, v)` 和 `m[k] = v` 是一回事**，后者顺手一点；
- `m[k]` **读**；`has(k)` 判断有没有；`remove(k)` 删掉并返回是否删到了；
- **遍历用 `keyAt(i)` / `valAt(i)` 按下标走**，`i` 从 0 到 `len() - 1`。
  Map 的遍历顺序是**按升序键**排列的，所以同一份数据每次遍历结果一致；

> **小心「查不存在的键」。** 上面 `ages["zoe"]` 返回了 `0`，而不是报错。
> 因为 `V` 是 `int64`，缺省值就是 0。
> **这不是「没有这个键」的意思**，而是「我按 0 处理了」——
> 想知道键在不在，先用 `has(k)` 问一次。这是 Map 最容易埋 bug 的地方。

## 11.3 `Set<T>`：不重复，自动升序

```magel
int64 main()
{
    Set<int64> unique;
    unique.add(5);
    unique.add(3);
    unique.add(5);
    // 重复的加不进去

    println("len={} has5={} has9={}", unique.len(), unique.has(5), unique.has(9));
    println("按升序看：at0={} at1={}", unique.at(0), unique.at(1));
    println("remove(5) 拿回 {}，现在 len={}", unique.remove(5), unique.len());
    return 0;
}
```

```text
len=2 has5=1 has9=0
按升序看：at0=3 at1=5
remove(5) 拿回 1，现在 len=1
```

`Set` 的两个特点：

- **自动去重**：`add(5)` 两次，长度还是 1；
- **自动排序**：遍历出来是**升序**（`at(0)` 是最小的）。

`remove` 返回的是「有没有删到」。所以「删一个可能不存在的元素」不用先查
`has`，看返回值就知道。

## 11.4 集合字面量

不想一行行 `push` 的时候，可以直接写：

```magel
int64 main()
{
    List<int64> order =
    {
        3, 1, 2
    };
    println("{} {}", order.len(), order[0]);

    Set<int64> numbers =
    {
        3, 1, 2
    };
    println("{}", numbers.len());

    Map<String, int64> table =
    {
        "a": 1, "b": 2
    };
    println("{} {}", table.len(), table["b"]);
    return 0;
}
```

```text
3 3
3
2 2
```

**同样一对花括号，左边的类型决定它是什么。**

| 左边写的类型 | `{...}` 的含义 |
| --- | --- |
| `List<T>` | 有序表，元素按写的顺序排 |
| `Set<T>` | 去重的集合，自动升序 |
| `Map<K,V>` | 键值对（括号里带冒号） |

跨类型写会报错——`List<int64> v = {"a": 1};` 里带了冒号，那是 `Map` 的形态：

```text
magel：集合字面量类型不匹配：map 不能初始化 List<int64>
```

空表也有讲究：`List<int64> v = {};` 是空表，`Set<int64> v = {};` 是空集，
类型必须写清楚（`auto x = {...};` 这种不给上下文的老写法仍然当成 `Set`）。

要 `List` 也可以继续 `push`（或者用第 17 章的 `collect()`），两条路都通。

## 11.5 数组：两种

除了容器，还有两种**数组**：

```magel
int64 main()
{
    int64 fixed[3];
    // 长度写在类型里
    fixed[0] = 1;
    fixed[1] = 2;
    fixed[2] = 3;
    println("{}", fixed[0] + fixed[1] + fixed[2]);

    int64 runtime[] = new[4];
    // 长度运行时决定
    runtime[0] = 10;
    println("{} {}", len(fixed), len(runtime));
    return 0;
}
```

```text
6
3 4
```

| 写法 | 长度 | 什么时候用 |
| --- | --- | --- |
| `T a[N]` | 编译期定死 | 大小你**知道**，要省内存、要对齐硬件 |
| `T a[] = new[n]` | 运行时决定 | 大小要算出来或者读进来 |

数组和 `List` 的区别：**数组长度不可变，`List` 可以 `push` / `pop`。**
日常业务逻辑几乎都用 `List`；数组留给「缓冲区」「硬件寄存器映射」
「性能敏感的定长表」这类场合。

`len(a)` 对数组和容器都能用。越界同样会被检查到。

## 11.6 别忘了：容器也是**值**

第 6 章那条规则对容器照旧。这一点在容器上最容易踩：

```magel
int64 main()
{
    List<int64> original;
    original.push(1);

    List<int64> copy = original;
    // 整表复制一份
    copy.push(2);

    println("original={} copy={}", original.len(), copy.len());
    return 0;
}
```

```text
original=1 copy=2
```

**`copy = original` 之后两张表毫无关系。** 从 Java / Python 过来的人第一次写
「把表传进函数想让它加元素」，会发现函数里加的东西外面看不到——

```magel
void addOne(List<int64> numbers)
{
    numbers.push(1);
    // 改的是副本！
}
```

要真的改到外面那张表，写引用：

```magel
void addOne(List<int64> mut& numbers)
{
    numbers.push(1);
}
// 调用：addOne(&numbers);
```

**这也是性能上的关键点**：容器一般都有一份堆上的数据，
按值传一次就是整份复制。**容器参数默认写 `const&` 或 `mut&`**，
除非你确实想要一份独立副本。

### 容器里的东西也是副本

```magel
struct Player
{
    String name;
    int64 score;
};

int64 main()
{
    List<Player> players;
    Player p;
    p.name = "amy";
    p.score = 30;
    players.push(p);
    // 存进去的是一份副本

    p.score = 99;
    // 改原来的 p
    println("表里还是 {}", players[0].score);

    Player back = players[0];
    // 取出来的也是副本
    back.score = 1;
    println("表里还是 {}", players[0].score);
    return 0;
}
```

```text
表里还是 30
表里还是 30
```

**存进去是副本、取出来也是副本。** 想原地改容器里的元素，得用引用（第 7 章）：
`for (Player mut& item in players)` 那类写法在讲完引用之后你就理解了。

> 字符串元素也一样：取出来的是**新的一份**，所以容器活得比某根字符串久也没关系。

### 容器归声明它的那一层

容器在离开作用域时自动释放（第 8 章）：

```magel
int64 main()
{
    {
        List<int64> inner;
        inner.push(1);
        inner.push(2);
        println("块里的表：len={}", inner.len());
    }
    // ← 这里把 inner 还回去了
    println("done");
    return 0;
}
```

```text
块里的表：len=2
done
```

不用手动释放，也不用担心泄漏。要提前还就 `delete inner;`。

## 11.7 遍历

**遍历用 `for-in`**，不要数下标：

```magel
int64 main()
{
    List<int64> scores;
    scores.push(12);
    scores.push(55);
    scores.push(41);

    int64 total = 0;
    int64 best = 0;
    for (int64 score in scores)
    {
        total = total + score;
        if (score > best)
        {
            best = score;
        }
    }
    println("总和 {} 最高 {}", total, best);
    return 0;
}
```

```text
总和 108 最高 55
```

`for-in` 遍历出来的是**元素的副本**，所以「边遍历边改」改不到容器。
要用下标改，就用 `for`：

<!-- no-run -->
```magel
for (int64 i = 0; i < scores.len(); i = i + 1)
{
    scores[i] = scores[i] + 10;
    // 这样才改到表里
}
```

> **遍历时不要增删元素。** `for-in` 途中 `push` / `remove` 会让「下一个是谁」
> 变得不可预测。要筛要删，用第 17 章的迭代器 `filter` / `collect` 造一张新表，
> 或者先记下要删的下标再统一删。

### 用 `Any` 保存不同类型的元素

`List<Any>` 明确要求元素装箱；`Set<Any>` 和 `Map` 的键或值槽也可以明确写成 `Any`。普通的 `List<int64>` 仍只接受能转换为 `int64` 的值。

<!-- verify-book -->
```magel
int64 main()
{
    List<Any> values = {1, "two", true};
    values.push(1.5);
    Any text = values[1];
    println("{} {}", values.len(), tryGet<String>(&text).unwrap());

    Set<Any> unique;
    Any key = "key";
    unique.add(key);
    unique.add(key);
    unique.add(2);
    println("{}", unique.len());

    Map<Any, Any> mixed;
    mixed.put(key, "stored");
    mixed.put(3, true);
    Any saved = mixed[key];
    println("{} {}", mixed.len(), tryGet<String>(&saved).unwrap());

    Map<String, Any> record = {"count": 3, "name": "Magel"};
    Any count = record["count"];
    println("{}", tryGet<int64>(&count).unwrap());
    saved.clear();
    println("{}", saved.isEmpty());
    return 0;
}
```

```text
4 two
2
2 stored
3
1
```

`Any` 保留精确类型，`tryGet<T>` 返回拥有值的副本；类型不匹配时返回 `None`。`clear()` 释放盒子当前载荷并恢复空状态，不影响之前复制出的值。字符串、嵌套容器按值复制，盒子和容器在离开作用域时自动清理。

**`Any` 键比较身份，不比较装箱内容。** 复制 `key` 保留身份，所以重复插入会去重，并且可以用它查询映射。两次独立装箱相同内容是不同键；需要按字符串内容查询时使用 `Map<String, Any>`。异构集合的排列也不要当成按载荷数值或文本排序。

装箱不会延长引用寿命。局部结构体、数组等多槽值的地址不能被保存在更长寿命的盒子里；需要接口视图时可直接绑定实现类型的引用，无须经过 `Any`。

## 11.8 小结

| 容器 | 常用操作 |
| --- | --- |
| `List<T>` | `push` `pop` `insert` `remove` `clear` `len` `at` `[]` `has` `indexOf` |
| `Map<K,V>` | `put` `[]` `has` `remove` `len` `keyAt` `valAt` |
| `Set<T>` | `add` `has` `remove` `len` `at` |

要记住的：

- 字面量：左边写 `List<T>` / `Set<T>` / `Map<K,V>` 决定 `{...}` 是什么，带冒号的是 `Map`；
- **越界是明确的运行期错误**，不是未定义行为；
- **`Map` 读不存在的键得到缺省值（不报错）**，先 `has` 再取；
- **容器是值**：赋值、传参、存取元素都是复制；传参默认写 `const&` / `mut&`；
- 遍历用 `for-in`，遍历出来是副本；**遍历时不要增删**；
- 容器在出作用域时自动释放。

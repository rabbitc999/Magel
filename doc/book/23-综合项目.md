# 第 23 章 综合项目：命令行待办清单

前二十二章，每一章解决一个问题。这一章把它们**串起来**：从零写一个真能用的小工具——
**命令行待办清单**。

它要能：

- 加一条待办、列出全部、标记完成、删掉一条；
- **把数据存到文件里**，下次打开还在；
- 处理「文件不存在」「序号不合法」这些真实世界的小意外。

写完你会发现：**几乎没有新语法**——全是前面学过的东西。

---

## 23.1 先想清楚数据长什么样

一个待办项有两样东西：**内容**和一个**完成标记**。用结构体（第 9 章）：

<!-- no-run -->
```magel
struct Task
{
    String text;
    bool done;
};
```

清单就是 `List<Task>`（第 11 章）。

**存储格式**也要现在定下来——这是设计里最容易忽略、又最影响后面代码的一步。
选一个**人能直接看懂**的格式：一行一条，`0` 或 `1` 表示完成，`|` 后面是内容。

```text
1|买菜
0|写作业
```

这样出问题时，用记事本打开就能查。

---

## 23.2 读：把文件变回清单

读文件用 `FileStream`（`import std::io;`，第 18 章讲的 import）。

这里有个**关键设计决定**：**文件不存在 = 空清单**，不当错误。

<!-- no-run -->
```magel
List<Task> loadTasks()
{
    List<Task> tasks;
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "r");
    if (opened.isErr())
    {
        return tasks;
    }
    FileStream stream = opened.unwrap();
    while (true)
    {
        Result<String, IoError> line = stream.read();
        if (line.isErr())
        {
            break;
        }
        String raw = std::text::Text::trim(line.unwrap());
        if (raw == "")
        {
            break;
        }
        Task t;
        t.done = std::text::Text::startsWith(raw, "1");
        int64 bar = std::text::Text::find(raw, "|");
        t.text = raw[bar + 1:];
        tasks.push(t);
    }
    stream.close();
    return tasks;
}
```

三处值得说：

- `FileStream::open` 返回 `Result`（第 16 章）。**打不开不是崩溃，是一个可以处理的结果**——
  这正是 `Result` 存在的意义；
- `stream.read()` 一次读一行。**读到头（EOF）返回的是空串 `Ok("")`，不是错误**——
  所以退出条件写成 `if (raw == "") { break; }`。这是实测踩出来的，别想当然写成 `isErr`；
- `raw[bar + 1:]` 是**切片**（第 12 章）。`|` 是 ASCII，字节边界天然合法，
  所以这里按字节切中文内容也没问题。

## 23.3 写：把清单存回文件

反过来，写文件是**先打开、逐行写、关闭**：

<!-- no-run -->
```magel
void saveTasks(List<Task> tasks)
{
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "w");
    if (opened.isErr())
    {
        println("无法写入 {}", storePath());
        return;
    }
    FileStream stream = opened.unwrap();
    for (Task t in tasks)
    {
        String flag = "0";
        if (t.done)
        {
            flag = "1";
        }
        stream.write(flag + "|" + t.text + "\n");
    }
    stream.close();
}
```

模式 `"w"` 是**覆盖写**——每次保存都整份重写。对几千条以内的清单，这足够快，
而且**不会出现"改一半"的中间状态**。

`for (Task t in tasks)` 拿到的 `t` 是**元素的副本**（第 6 章值语义），
因此这里只读不改；要改得按下标写回去（`done` 命令就这么做的）。

## 23.4 命令分派：`main` 是入口

程序接收命令行参数，靠的是**带参的 `main`**（第 4 章）：

<!-- no-run -->
```magel
int64 main(List<String> args)
{
    …
}
```

`args` 是**不含程序名**的参数列表。所以 `todo add 买菜` 传进来的是
`["add", "买菜"]`。

命令分派就是一串 `if`（第 5 章），**每种命令都返回一个退出码**：

<!-- no-run -->
```magel
String command = args[0];
List<Task> tasks = loadTasks();

if (command == "add")
{
    String text = joinFrom(args, 1);
    if (text == "")
    {
        println("add 后面要写内容");
        return 1;
    }
    Task t;
    t.text = text;
    t.done = false;
    tasks.push(t);
    saveTasks(tasks);
    println("已添加，现在有 {} 条", tasks.len());
    return 0;
}
```

两个小设计：

- **`add` 后面的内容可以带空格**：`joinFrom(args, 1)` 把第 2 个参数起的部分用空格拼起来
  （`std::text::Text::join`）。于是 `add 周五 下午 交 报告` 存的就是一整句；
- **每一档都 `return`**：用返回码告诉外面「成功（0）」还是「用法错（1）」——
  这正是第 1 章 `main` 返回 0 那个约定的用法。

序号参数是字符串，要转成整数：`std::parse::Parse::parseInt64` 返回 `Result`，
所以用第 16 章的 `isErr` 来兜底：

<!-- no-run -->
```magel
int64 parseIntOr(String s, int64 fallback)
{
    Result<int64, ParseError> r = std::parse::Parse::parseInt64(s);
    if (r.isErr())
    {
        return fallback;
    }
    return r.unwrap();
}
```

传个 `done abc` 进来，`parseInt64` 失败 → 返回兜底值 0 → 后面「序号超出范围」的判断把它挡住。
**非法输入没有变成崩溃，而是变成一句人话提示。**

## 23.5 完整程序

把上面几块拼起来。整份代码（**这段可以整段复制出去跑**）：

```magel
import std::io;
import std::text;
import std::parse;

struct Task
{
    String text;
    bool done;
};

String storePath()
{
    return "todo.txt";
}

List<Task> loadTasks()
{
    List<Task> tasks;
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "r");
    if (opened.isErr())
    {
        return tasks;
    }
    FileStream stream = opened.unwrap();
    while (true)
    {
        Result<String, IoError> line = stream.read();
        if (line.isErr())
        {
            break;
        }
        String raw = std::text::Text::trim(line.unwrap());
        if (raw == "")
        {
            break;
        }
        Task t;
        t.done = std::text::Text::startsWith(raw, "1");
        int64 bar = std::text::Text::find(raw, "|");
        t.text = raw[bar + 1:];
        tasks.push(t);
    }
    stream.close();
    return tasks;
}

void saveTasks(List<Task> tasks)
{
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "w");
    if (opened.isErr())
    {
        println("无法写入 {}", storePath());
        return;
    }
    FileStream stream = opened.unwrap();
    for (Task t in tasks)
    {
        String flag = "0";
        if (t.done)
        {
            flag = "1";
        }
        stream.write(flag + "|" + t.text + "\n");
    }
    stream.close();
}

void printTasks(List<Task> tasks)
{
    if (tasks.len() == 0)
    {
        println("（清单是空的，用 add 加一条）");
        return;
    }
    int64 i = 1;
    for (Task t in tasks)
    {
        String mark = "[ ]";
        if (t.done)
        {
            mark = "[x]";
        }
        println("{} {} {}", i, mark, t.text);
        i = i + 1;
    }
}

int64 parseIntOr(String s, int64 fallback)
{
    Result<int64, ParseError> r = std::parse::Parse::parseInt64(s);
    if (r.isErr())
    {
        return fallback;
    }
    return r.unwrap();
}

String joinFrom(List<String> args, int64 start)
{
    List<String> rest;
    for (int64 i = start; i < args.len(); i = i + 1)
    {
        rest.push(args[i]);
    }
    return std::text::Text::join(rest, " ");
}

void usage()
{
    println("用法：todo <命令> [参数]");
    println("  add <内容>    加一条待办");
    println("  list          列出全部");
    println("  done <序号>   标记完成");
    println("  remove <序号> 删除一条");
    println("  clear         清空");
}

int64 main(List<String> args)
{
    if (args.len() == 0)
    {
        usage();
        return 0;
    }

    String command = args[0];
    List<Task> tasks = loadTasks();

    if (command == "add")
    {
        String text = joinFrom(args, 1);
        if (text == "")
        {
            println("add 后面要写内容");
            return 1;
        }
        Task t;
        t.text = text;
        t.done = false;
        tasks.push(t);
        saveTasks(tasks);
        println("已添加，现在有 {} 条", tasks.len());
        return 0;
    }

    if (command == "list")
    {
        printTasks(tasks);
        return 0;
    }

    if (command == "done")
    {
        if (args.len() < 2)
        {
            println("done 后面要写序号");
            return 1;
        }
        int64 index = parseIntOr(args[1], 0);
        if (index < 1 || index > tasks.len())
        {
            println("序号超出范围");
            return 1;
        }
        Task t = tasks[index - 1];
        t.done = true;
        tasks[index - 1] = t;
        saveTasks(tasks);
        println("完成：{}", t.text);
        return 0;
    }

    if (command == "remove")
    {
        if (args.len() < 2)
        {
            println("remove 后面要写序号");
            return 1;
        }
        int64 index = parseIntOr(args[1], 0);
        if (index < 1 || index > tasks.len())
        {
            println("序号超出范围");
            return 1;
        }
        List<Task> kept;
        int64 i = 1;
        for (Task t in tasks)
        {
            if (i != index)
            {
                kept.push(t);
            }
            i = i + 1;
        }
        saveTasks(kept);
        println("已删除第 {} 条", index);
        return 0;
    }

    if (command == "clear")
    {
        List<Task> empty;
        saveTasks(empty);
        println("已清空");
        return 0;
    }

    println("未知命令：{}", command);
    usage();
    return 1;
}
```

直接 `magel run todo.mgl`（不带参数），它会打印用法：

```text
用法：todo <命令> [参数]
  add <内容>    加一条待办
  list          列出全部
  done <序号>   标记完成
  remove <序号> 删除一条
  clear         清空
```

把这段存成 `todo.mgl`，下面就真能用了。

## 23.6 跑一遍

先清空，然后加两条、看一眼：

```sh
magel run todo.mgl -- clear
magel run todo.mgl -- add 买菜
magel run todo.mgl -- add 写作业
magel run todo.mgl -- list
```

```text
已清空
已添加，现在有 1 条
已添加，现在有 2 条
1 [ ] 买菜
2 [ ] 写作业
```

> `--` 后面的东西原样传给**程序自己**（第 1 章讲过 `run` 和 `check` 的区别时提过参数传递）。
> 没有 `--`，`clear` 会被当成 `magel` 的选项。

标记完成、再看、然后删掉第一条：

```sh
magel run todo.mgl -- done 2
magel run todo.mgl -- list
magel run todo.mgl -- remove 1
magel run todo.mgl -- list
```

```text
完成：写作业
1 [ ] 买菜
2 [x] 写作业
已删除第 1 条
1 [x] 写作业
```

数据真的落盘了——`todo.txt` 里是这样（人能直接读懂）：

```text
1|写作业
```

再试几个「不老实」的输入：

```sh
magel run todo.mgl -- done abc
magel run todo.mgl -- add 周五 下午 交 报告
magel run todo.mgl -- list
```

```text
序号超出范围
已添加，现在有 2 条
1 [x] 写作业
2 [ ] 周五 下午 交 报告
```

`done abc` 没有崩，而是回了一句「序号超出范围」；`add` 后面带空格的整句也完整存下来了。

**关掉重开，数据还在**——这就是 `loadTasks` / `saveTasks` 那二十来行的价值。

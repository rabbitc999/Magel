\chapter{迭代器}
\label{ch:17}

第 15 章你手写过一个 \texttt{filter}：自己声明 \texttt{List}、自己 \texttt{for-in}、自己 \texttt{push}。能跑，但每换一种操作——求平方、取前几个、求和——都得再手搓一遍循环。

这一章讲 \texttt{std:\allowbreak{}:\allowbreak{}iter}：它把这些套路做成了能随意拼的链。写起来像说话，读起来也像说话：

\par
\medskip
\begin{lstlisting}[style=magel]
std::iter::range(1, 100).filter(是偶数).map(乘十).take(3).collect()
\end{lstlisting}
\par
\medskip

\section{一条链由三段组成}

迭代器的写法永远是同一个形状：

\par
\medskip
\begin{lstlisting}[style=magel]
起点.中间操作.中间操作.….终结操作
\end{lstlisting}
\par
\medskip

\begin{itemize}

\item 起点：从哪儿开始——一个区间、一个列表；

\item 中间操作：\texttt{map} / \texttt{filter} / \texttt{take}……可以串好几个；

\item 终结操作：\texttt{collect} / \texttt{fold} / \texttt{count}……干活的是它。

\end{itemize}

要 import：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;
\end{lstlisting}
\par
\medskip

\section{起点：\texttt{range} 和 \texttt{List.\allowbreak{}iter(\allowbreak{})\allowbreak{}}}

最常用的起点是 \texttt{std:\allowbreak{}:\allowbreak{}iter:\allowbreak{}:\allowbreak{}range(\allowbreak{}start,\allowbreak{} stop)\allowbreak{}}——从 \texttt{start} 到 \texttt{stop}（不含 \texttt{stop}）：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    auto xs = std::iter::range(1, 6).collect();
    println("{} {}", xs.len(), xs[4]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
5 5
\end{lstlisting}
\par
\medskip

\texttt{range(\allowbreak{}1,\allowbreak{} 6)\allowbreak{}} 数是 1、2、3、4、5——和切片一样左闭右开（第 12 章）。\texttt{collect(\allowbreak{})\allowbreak{}} 把它们收进一个 \texttt{List<\allowbreak{}int64>\allowbreak{}}。

还有一个重载可以指定步长：\texttt{range(\allowbreak{}start,\allowbreak{} stop,\allowbreak{} step)\allowbreak{}}。

另一种起点是从现成的容器出发：\texttt{列表.\allowbreak{}iter(\allowbreak{})\allowbreak{}}。它和 \texttt{range} 有一个重要区别——\texttt{range} 每次调用都造一条新链，而容器迭代器是一次性消费品（见 17.8）。

\section{中间操作：\texttt{map} / \texttt{filter} / \texttt{take} / \texttt{skip} / \texttt{rev}}

\texttt{map}——对每一项做同一个变换：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    auto ys = std::iter::range(1, 6).map(fn(int64 x)
    {
        x * x
    }).collect();
    println("{} {} {}", ys[0], ys[1], ys[4]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
1 4 25
\end{lstlisting}
\par
\medskip

\texttt{filter}——只留下满足条件的：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    auto evens = std::iter::range(1, 11)
    .filter(fn(int64 x)
    {
        x % 2 == 0
    })
    .collect();
    println("{} -> {} {} {}", evens.len(), evens[0], evens[1], evens[4]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
5 -> 2 4 10
\end{lstlisting}
\par
\medskip

\texttt{take(\allowbreak{}n)\allowbreak{}} / \texttt{skip(\allowbreak{}n)\allowbreak{}} 取前 n 个 / 跳过前 n 个；\texttt{rev(\allowbreak{})\allowbreak{}} 反转。它们和 \texttt{map} / \texttt{filter} 一样，都是「中间操作」，返回的还是迭代器，可以继续往下接。

\section{终结操作：\texttt{collect} / \texttt{fold} / \texttt{count}}

中间操作只是搭管道，真正让数据流动的是终结操作。常用的三个：

\begin{itemize}

\item \texttt{collect(\allowbreak{})\allowbreak{}} —— 收成一个 \texttt{List}；

\item \texttt{count(\allowbreak{})\allowbreak{}} —— 数一共多少个；

\item \texttt{fold(\allowbreak{}初值,\allowbreak{} 函数)\allowbreak{}} —— 从头到尾累积，最灵活。

\end{itemize}

\texttt{fold} 是「求和、求积、求最大」这类操作的通用形式。求和：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    int64 s = std::iter::range(1, 101).fold(0, fn(int64 acc, int64 x)
    {
        acc + x
    });
    println("{}", s);
    println("{}", std::iter::range(1, 101).count());
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
5050
100
\end{lstlisting}
\par
\medskip

\texttt{fold(\allowbreak{}0,\allowbreak{} …)\allowbreak{}} 里那个 \texttt{0} 是初值 \texttt{acc}，然后每来一个 \texttt{x}，用函数算出一个新的 \texttt{acc}：\texttt{0 → 0+1 → 1+2 → …}。想求最大值，初值给一个极小值，函数换成「取较大的」就行。

还有几个「问一句就走」的终结操作：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    println("{}", std::iter::range(1, 6).all(fn(int64 x)
    {
        x > 0
    }));
    println("{}", std::iter::range(1, 6).any(fn(int64 x)
    {
        x > 3
    }));
    println("{}", std::iter::range(1, 6).find(fn(int64 x)
    {
        x % 2 == 0
    }).unwrap());
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
1
1
2
\end{lstlisting}
\par
\medskip

\begin{itemize}

\item \texttt{all(\allowbreak{}pred)\allowbreak{}} 全满足吗；\texttt{any(\allowbreak{}pred)\allowbreak{}} 有满足的吗——都返回 \texttt{bool}；

\item \texttt{find(\allowbreak{}pred)\allowbreak{}} 返回第一个满足的（\texttt{Option}，第 16 章——所以后面能接 \texttt{.\allowbreak{}unwrap(\allowbreak{})\allowbreak{}}）。

\end{itemize}

\section{串成一条链}

现在把中间操作串起来看威力——「1 到 99 里，乘 2 之后能被 3 整除的前 3 个」：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    auto ys = std::iter::range(1, 100)
    .map(fn(int64 x)
    {
        x * 2
    })
    .filter(fn(int64 x)
    {
        x % 3 == 0
    })
    .take(3)
    .collect();
    println("{} {} {} {}", ys.len(), ys[0], ys[1], ys[2]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
3 6 12 18
\end{lstlisting}
\par
\medskip

一行一句、从上往下读，和需求一一对应：\texttt{map} 乘 2、\texttt{filter} 要 3 的倍数、\texttt{take(\allowbreak{}3)\allowbreak{}} 取三个、\texttt{collect} 收起来。没有 \texttt{for-in}、没有下标、没有临时变量。

\section{惰性：写了 \ensuremath{\neq} 跑了}

这是迭代器最容易误解的地方。看下面这段：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 seen = 0;

void note(int64 x)
{
    seen = seen + 1;
}

int64 main()
{
    auto lazy = std::iter::range(1, 6)
    .inspect(note)
    .map(fn(int64 x)
    {
        x * 10
    });
    println("{}", seen);

    auto got = lazy.collect();
    println("{} {}", seen, got[0]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
0
5 10
\end{lstlisting}
\par
\medskip

\texttt{inspect} 是个「顺手看一眼」的中间操作——每过一项就调用一次 \texttt{note}。可注意：

\begin{itemize}

\item 第一次打印 \texttt{seen} 是 0——虽然链子搭好了，一项都还没走；

\item 直到 \texttt{.\allowbreak{}collect(\allowbreak{})\allowbreak{}} 那一刻，才真的从头跑到尾，\texttt{seen} 变成 5。

\end{itemize}

中间操作是惰性的：不接终结操作，它们一行都不执行。 这条设计有两个好处：

\begin{enumerate}

\item 省事——\texttt{take(\allowbreak{}3)\allowbreak{}} 时，源数据只要产出 3 个就够了，后面的根本不碰；

\item 能做无限序列——\texttt{std:\allowbreak{}:\allowbreak{}iter:\allowbreak{}:\allowbreak{}repeat(\allowbreak{}x)\allowbreak{}} 可以永远产下去，只要你用 \texttt{take} 限住。

\end{enumerate}

\begin{tip}{提示}
记住一句话：迭代器链只有碰到 \texttt{collect} / \texttt{fold} / \texttt{count} 这类终结操作才会开跑。
\end{tip}

\section{一个坑：\texttt{List.\allowbreak{}iter(\allowbreak{})\allowbreak{}} 的元素是引用}

\texttt{range} 产出的是实打实的 \texttt{int64}，所以 \texttt{fn(\allowbreak{}int64 x)\allowbreak{}} 就够了。但从列表出发时，\texttt{列表.\allowbreak{}iter(\allowbreak{})\allowbreak{}} 产出的是元素的只读引用，fn 的参数得写成引用：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    List<int64> xs;
    xs.push(10);
    xs.push(20);
    xs.push(30);
    int64 total = xs.iter().fold(0, fn(int64 acc, int64 const& x)
    {
        acc + x
    });
    println("{}", total);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
60
\end{lstlisting}
\par
\medskip

写 \texttt{fn(\allowbreak{}int64 acc,\allowbreak{} int64 x)\allowbreak{}} 会报「类型实参推导冲突」——因为元素实际是\texttt{int64 const\&}。这是借用检查器在提醒你：\texttt{.\allowbreak{}iter(\allowbreak{})\allowbreak{}} 借用了那个列表，而不是把它复制一份（省内存，也符合第 7 章「引用」那一套）。

要原地改元素，用 \texttt{.\allowbreak{}iter\allowbreak{}Mut(\allowbreak{})\allowbreak{}}——它产出可写引用 \texttt{T mut\&}（第 7 章）：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

void bump(int64 mut& x)
{
    x = x * 10;
}

int64 main()
{
    List<int64> xs;
    xs.push(1);
    xs.push(2);
    xs.push(3);
    xs.iterMut().forEach(bump);
    println("{} {} {}", xs[0], xs[1], xs[2]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
10 20 30
\end{lstlisting}
\par
\medskip

\texttt{bump} 拿到的是可写引用，所以它改的就是列表里的原件。

不想借、想要一份独立的元素值，用 \texttt{.\allowbreak{}into\allowbreak{}Iter(\allowbreak{})\allowbreak{}}——它拿走列表的元素，fn 参数写 \texttt{int64} 就行。

\begin{center}
\begin{tabular}{lll}
\toprule
你想要 & 用 & 元素类型 \\
\midrule
只读遍历 & \texttt{xs.\allowbreak{}iter(\allowbreak{})\allowbreak{}} & \texttt{T const\&} \\
边走边改元素 & \texttt{xs.\allowbreak{}iter\allowbreak{}Mut(\allowbreak{})\allowbreak{}} & \texttt{T mut\&} \\
拿走元素 & \texttt{xs.\allowbreak{}into\allowbreak{}Iter(\allowbreak{})\allowbreak{}} & \texttt{T} \\
\bottomrule
\end{tabular}
\end{center}

\section{迭代器是一次性消费品}

17.2 留的那个问题现在回答：\texttt{range} 和 \texttt{列表.\allowbreak{}iter(\allowbreak{})\allowbreak{}} 的区别是——迭代器只能从头到尾走一遍。走完之后再调 \texttt{next(\allowbreak{})\allowbreak{}}、再接 \texttt{all} / \texttt{any} / \texttt{fold}，得到的都是空：不会报错，就是没有数据。

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    List<int64> xs;
    xs.push(1);
    xs.push(2);
    xs.push(3);
    xs.push(4);
    auto first = xs.iter();
    println("第一次 all: {}", first.all(fn(int64 const& x)
    {
        x > 0
    }));
    println("第二次 any: {}", first.any(fn(int64 const& x)
    {
        x > 2
    }));
    auto second = xs.iter();
    println("新建后 any: {}", second.any(fn(int64 const& x)
    {
        x > 2
    }));
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
第一次 all: 1
第二次 any: 0
新建后 any: 1
\end{lstlisting}
\par
\medskip

\texttt{first} 被 \texttt{all} 走完就耗干了，第二次 \texttt{any} 是在空迭代器上问的——答案当然是「没有」。想再走一遍，就再调一次 \texttt{xs.\allowbreak{}iter(\allowbreak{})\allowbreak{}} 造一条新的（\texttt{second} 那两行）。\texttt{range} 没这个烦恼，因为它每次调用本来就是一条新链。

记住一句话：迭代器是一次性的，链子要走第二遍就重新造起点。

\subsection{从列表造起点：\texttt{from\allowbreak{}List}}

\texttt{std:\allowbreak{}:\allowbreak{}iter:\allowbreak{}:\allowbreak{}from\allowbreak{}List<\allowbreak{}T>\allowbreak{}(\allowbreak{}list)\allowbreak{}} 也是一条起点：把列表的元素复制进迭代器，原来的列表完好无损：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    List<int64> xs;
    xs.push(2);
    xs.push(4);
    xs.push(6);
    int64 total = fromList<int64>(xs).fold(0, fn(int64 acc, int64 x)
    {
        acc + x
    });
    println("{} {}", total, xs.len());
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
12 3
\end{lstlisting}
\par
\medskip

\subsection{\texttt{Set.\allowbreak{}iter(\allowbreak{})\allowbreak{}} 与 \texttt{Map.\allowbreak{}iter(\allowbreak{})\allowbreak{}}}

\texttt{Set<\allowbreak{}T>\allowbreak{}} 和 \texttt{Map<\allowbreak{}K,\allowbreak{}V>\allowbreak{}} 同样有 \texttt{.\allowbreak{}iter(\allowbreak{})\allowbreak{}}：借用快照——把元素（Map 是 \texttt{(\allowbreak{}K,\allowbreak{} V)\allowbreak{}} 元组）复制进迭代器，来源容器保持不变；对应的 \texttt{.\allowbreak{}into\allowbreak{}Iter(\allowbreak{})\allowbreak{}} 则把容器搬空。

\par
\medskip
\begin{lstlisting}[style=magel]
import std::iter;

int64 main()
{
    Set<int64> s;
    s.add(1);
    s.add(2);
    s.add(3);
    auto si = s.iter();
    int64 sum = 0;
    loop
    {
        match(si.next())
        {
            Value(v) => { sum = sum + v; }
            None => { break; }
        }
    };
    println("sum = {} len = {}", sum, s.len());
    Map<int64, int64> m;
    m.put(1, 10);
    m.put(2, 20);
    auto mi = m.iter();
    int64 doubled = 0;
    loop
    {
        match(mi.next())
        {
            Value(pair) => { doubled = doubled + pair.0 * pair.1; }
            None => { break; }
        }
    };
    println("doubled = {} len = {}", doubled, m.len());
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
sum = 6 len = 3
doubled = 50 len = 2
\end{lstlisting}
\par
\medskip

迭代完了 \texttt{s.\allowbreak{}len(\allowbreak{})\allowbreak{}} 还是 3、\texttt{m.\allowbreak{}len(\allowbreak{})\allowbreak{}} 还是 2——借用快照不动原件。Map 的每一项是元组，用 \texttt{pair.\allowbreak{}0} 取键、\texttt{pair.\allowbreak{}1} 取值。

\section{for-in：把链条跑起来}

前面几节一直在"造一条链"，真正让它跑起来的是 \texttt{for-in}。三种写法：

\par
\medskip
\begin{lstlisting}[style=magel]
for (int64 a in list)
{
    ...
}
/* 写上类型 */
for (a in list)
{
    ...
}
/* 省略类型，按元素推 */
for (int64 mut& p in span)
{
    ...
}
/* 引用形态：拿到元素地址 */
\end{lstlisting}
\par
\medskip

能当迭代源的有：数组、\texttt{List<\allowbreak{}T>\allowbreak{}}、\texttt{std:\allowbreak{}:\allowbreak{}memory:\allowbreak{}:\allowbreak{}Span<\allowbreak{}T>\allowbreak{}}、自己写的 \texttt{Iterator<\allowbreak{}T>\allowbreak{}}，以及整数区间（见 17.11）。\texttt{break} / \texttt{continue} 照常可用：

\par
\medskip
\begin{lstlisting}[style=magel]
int64 partial = 0;
for (int64 i in [0, 10])
{
    if (i == 3)
    {
        continue;
    }
    /* 跳过 3 */
    if (i == 6)
    {
        break;
    }
    /* 到 6 就收工 */
    partial = partial + i;
}
println("break/continue: {}", partial);
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
break/continue: 12
\end{lstlisting}
\par
\medskip

\texttt{0 + 1 + 2}，跳过 \texttt{3}，再加 \texttt{4}、\texttt{5}，撞上 \texttt{6} 退出 —— 一共 12。

\section{for-in 拿到的是元素引用（最容易踩的一个坑）}

循环变量不是副本，它是元素本身。 给它赋值会直接写回容器：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::collections;

int64 main()
{
    int64 raw[] = new[3];
    raw[0] = 1;
    raw[1] = 2;
    raw[2] = 3;
    for (int64 a in raw)
    {
        a = a * 10;
    }
    println("array: {} {} {}", raw[0], raw[1], raw[2]);

    List<int64> list;
    list.push(4);
    list.push(5);
    for (int64 a in list)
    {
        a = a + 1;
    }
    println("list: {} {}", list[0], list[1]);
    return 0;
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
array: 10 20 30
list: 5 6
\end{lstlisting}
\par
\medskip

不少语言里 \texttt{for (\allowbreak{}x in xs)\allowbreak{}} 的 \texttt{x} 是一份拷贝，改它不影响容器 —— Magel 正好相反。想"只读地看一遍"就别给它赋值；想原地改，这反而是最省事的写法，连下标都不用写。

\subsection{\texttt{mut\&}：拿地址，而不是元素}

\texttt{Span<\allowbreak{}T>\allowbreak{}} 这类"引用 + 长度"的视图，迭代器返回的是 \texttt{Option<\allowbreak{}T mut\&>\allowbreak{}}。这时用 \texttt{T mut\&} 形态能直接拿到元素地址，改结构体字段特别顺手：

\par
\medskip
\begin{lstlisting}[style=magel]
std::memory::Span<int64> span = std::memory::Span<int64>::from(raw, len(raw));
for (int64 mut& p in span)
{
    * p = *p + 1;
}
\end{lstlisting}
\par
\medskip

\texttt{*p =\allowbreak{} *p + 1} 写回原缓冲区，不复制元素；结构体就写 \texttt{p->\allowbreak{}weight =\allowbreak{} .\allowbreak{}.\allowbreak{}.\allowbreak{}}。反过来，值容器用值形态就够了 —— \texttt{List<\allowbreak{}int64>\allowbreak{}} 的元素是 \texttt{int64} 而不是引用，对它写 \texttt{mut\&} 编译器会直接拦下来：

\par
\medskip
\begin{lstlisting}[style=magel]
List<int64> list;
list.push(1);
for (int64 mut& x in list)
{
}
\end{lstlisting}
\par
\medskip

\par
\medskip
\begin{lstlisting}[style=out]
magel：for-in 变量类型与 Vector<T> 元素不一致：写的是 int64 mut&，容器元素是 int64
\end{lstlisting}
\par
\medskip

判断方法就一句：你要改的是"元素的值"还是"元素本身的位置" —— 前者写值形态，后者（指针视图、想省掉一次拷贝）才用 \texttt{mut\&}。

\section{for-in 整数区间}

\texttt{for (\allowbreak{}uint8 x in [\allowbreak{}0,\allowbreak{}255]\allowbreak{})\allowbreak{} \{ .\allowbreak{}.\allowbreak{}.\allowbreak{} \}} 依次产生 0 到 255，共 256 项；\texttt{[\allowbreak{}0,\allowbreak{}255)\allowbreak{}} 不包含 255。支持 int8/uint8/int16/uint16/int32/uint32/int64/uint64。省略变量类型时按端点整型推导，普通整数字面量默认 int64。

区间在内部表示为惰性 \texttt{Iterator<\allowbreak{}T>\allowbreak{}}，直接复用 for-in 的迭代协议，不创建列表。两个端点从左到右各求值一次，并且两个端点都必须在 T 的取值范围内，包括半开区间的上端点。常量错误在编译期拒绝，动态端点在循环前检查。int8 的范围是 -128..127，所以 \texttt{for(\allowbreak{}int8 x in [\allowbreak{}0,\allowbreak{}255]\allowbreak{})\allowbreak{}} 会报错。反向区间 a>b 报错；[a,a) 是空区间，[a,a] 恰好产生一项。

闭区间到达上界后直接结束，不计算“最大整数 + 1”，因此 uint8 255 和 uint64 18446744073709551615 均可作为合法闭上界。循环变量是每轮取得的值，修改它不改变内部迭代进度；break、continue、返回与 fn 捕获沿用现有规则。

\chapter{综合项目：命令行待办清单}
\label{ch:23}

前二十二章，每一章解决一个问题。这一章把它们串起来：从零写一个真能用的小工具——命令行待办清单。

它要能：

\begin{itemize}

\item 加一条待办、列出全部、标记完成、删掉一条；

\item 把数据存到文件里，下次打开还在；

\item 处理「文件不存在」「序号不合法」这些真实世界的小意外。

\end{itemize}

写完你会发现：几乎没有新语法——全是前面学过的东西。

\section{先想清楚数据长什么样}

一个待办项有两样东西：内容和一个完成标记。用结构体（第 9 章）：

\par
\medskip
\begin{lstlisting}[style=magel]
struct Task
{
    String text;
    bool done;
};
\end{lstlisting}
\par
\medskip

清单就是 \texttt{List<\allowbreak{}Task>\allowbreak{}}（第 11 章）。

存储格式也要现在定下来——这是设计里最容易忽略、又最影响后面代码的一步。选一个人能直接看懂的格式：一行一条，\texttt{0} 或 \texttt{1} 表示完成，\texttt{|} 后面是内容。

\par
\medskip
\begin{lstlisting}[style=out]
1|买菜
0|写作业
\end{lstlisting}
\par
\medskip

这样出问题时，用记事本打开就能查。

\section{读：把文件变回清单}

读文件用 \texttt{File\allowbreak{}Stream}（\texttt{import std:\allowbreak{}:\allowbreak{}io;}，第 18 章讲的 import）。

这里有个关键设计决定：文件不存在 = 空清单，不当错误。

\par
\medskip
\begin{lstlisting}[style=magel]
List<Task> loadTasks()
{
    List<Task> tasks;
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "r");
    if (opened.isErr())
    {
        return tasks;
    }
    FileStream stream = opened.unwrap();
    while (true)
    {
        Result<String, IoError> line = stream.read();
        if (line.isErr())
        {
            break;
        }
        String raw = std::text::Text::trim(line.unwrap());
        if (raw == "")
        {
            break;
        }
        Task t;
        t.done = std::text::Text::startsWith(raw, "1");
        int64 bar = std::text::Text::find(raw, "|");
        t.text = raw[bar + 1:];
        tasks.push(t);
    }
    stream.close();
    return tasks;
}
\end{lstlisting}
\par
\medskip

三处值得说：

\begin{itemize}

\item \texttt{File\allowbreak{}Stream:\allowbreak{}:\allowbreak{}open} 返回 \texttt{Result}（第 16 章）。打不开不是崩溃，是一个可以处理的结果——这正是 \texttt{Result} 存在的意义；

\item \texttt{stream.\allowbreak{}read(\allowbreak{})\allowbreak{}} 一次读一行。读到头（EOF）返回的是空串 \texttt{Ok(\allowbreak{}"")\allowbreak{}}，不是错误——所以退出条件写成 \texttt{if (\allowbreak{}raw =\allowbreak{}=\allowbreak{} "")\allowbreak{} \{ break; \}}。这是实测踩出来的，别想当然写成 \texttt{is\allowbreak{}Err}；

\item \texttt{raw[\allowbreak{}bar + 1:\allowbreak{}]\allowbreak{}} 是切片（第 12 章）。\texttt{|} 是 ASCII，字节边界天然合法，所以这里按字节切中文内容也没问题。

\end{itemize}

\section{写：把清单存回文件}

反过来，写文件是先打开、逐行写、关闭：

\par
\medskip
\begin{lstlisting}[style=magel]
void saveTasks(List<Task> tasks)
{
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "w");
    if (opened.isErr())
    {
        println("无法写入 {}", storePath());
        return;
    }
    FileStream stream = opened.unwrap();
    for (Task t in tasks)
    {
        String flag = "0";
        if (t.done)
        {
            flag = "1";
        }
        stream.write(flag + "|" + t.text + "\n");
    }
    stream.close();
}
\end{lstlisting}
\par
\medskip

模式 \texttt{"w"} 是覆盖写——每次保存都整份重写。对几千条以内的清单，这足够快，而且不会出现"改一半"的中间状态。

\texttt{for (\allowbreak{}Task t in tasks)\allowbreak{}} 拿到的 \texttt{t} 是元素的副本（第 6 章值语义），因此这里只读不改；要改得按下标写回去（\texttt{done} 命令就这么做的）。

\section{命令分派：\texttt{main} 是入口}

程序接收命令行参数，靠的是带参的 \texttt{main}（第 4 章）：

\par
\medskip
\begin{lstlisting}[style=magel]
int64 main(List<String> args)
{
    …
}
\end{lstlisting}
\par
\medskip

\texttt{args} 是不含程序名的参数列表。所以 \texttt{todo add 买菜} 传进来的是\texttt{[\allowbreak{}"add",\allowbreak{} "买菜"]\allowbreak{}}。

命令分派就是一串 \texttt{if}（第 5 章），每种命令都返回一个退出码：

\par
\medskip
\begin{lstlisting}[style=magel]
String command = args[0];
List<Task> tasks = loadTasks();

if (command == "add")
{
    String text = joinFrom(args, 1);
    if (text == "")
    {
        println("add 后面要写内容");
        return 1;
    }
    Task t;
    t.text = text;
    t.done = false;
    tasks.push(t);
    saveTasks(tasks);
    println("已添加，现在有 {} 条", tasks.len());
    return 0;
}
\end{lstlisting}
\par
\medskip

两个小设计：

\begin{itemize}

\item \texttt{add} 后面的内容可以带空格：\texttt{join\allowbreak{}From(\allowbreak{}args,\allowbreak{} 1)\allowbreak{}} 把第 2 个参数起的部分用空格拼起来（\texttt{std:\allowbreak{}:\allowbreak{}text:\allowbreak{}:\allowbreak{}Text:\allowbreak{}:\allowbreak{}join}）。于是 \texttt{add 周五 下午 交 报告} 存的就是一整句；

\item 每一档都 \texttt{return}：用返回码告诉外面「成功（0）」还是「用法错（1）」——这正是第 1 章 \texttt{main} 返回 0 那个约定的用法。

\end{itemize}

序号参数是字符串，要转成整数：\texttt{std:\allowbreak{}:\allowbreak{}parse:\allowbreak{}:\allowbreak{}Parse:\allowbreak{}:\allowbreak{}parse\allowbreak{}Int64} 返回 \texttt{Result}，所以用第 16 章的 \texttt{is\allowbreak{}Err} 来兜底：

\par
\medskip
\begin{lstlisting}[style=magel]
int64 parseIntOr(String s, int64 fallback)
{
    Result<int64, ParseError> r = std::parse::Parse::parseInt64(s);
    if (r.isErr())
    {
        return fallback;
    }
    return r.unwrap();
}
\end{lstlisting}
\par
\medskip

传个 \texttt{done abc} 进来，\texttt{parse\allowbreak{}Int64} 失败 \ensuremath{\rightarrow} 返回兜底值 0 \ensuremath{\rightarrow} 后面「序号超出范围」的判断把它挡住。非法输入没有变成崩溃，而是变成一句人话提示。

\section{完整程序}

把上面几块拼起来。整份代码（这段可以整段复制出去跑）：

\par
\medskip
\begin{lstlisting}[style=magel]
import std::io;
import std::text;
import std::parse;

struct Task
{
    String text;
    bool done;
};

String storePath()
{
    return "todo.txt";
}

List<Task> loadTasks()
{
    List<Task> tasks;
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "r");
    if (opened.isErr())
    {
        return tasks;
    }
    FileStream stream = opened.unwrap();
    while (true)
    {
        Result<String, IoError> line = stream.read();
        if (line.isErr())
        {
            break;
        }
        String raw = std::text::Text::trim(line.unwrap());
        if (raw == "")
        {
            break;
        }
        Task t;
        t.done = std::text::Text::startsWith(raw, "1");
        int64 bar = std::text::Text::find(raw, "|");
        t.text = raw[bar + 1:];
        tasks.push(t);
    }
    stream.close();
    return tasks;
}

void saveTasks(List<Task> tasks)
{
    Result<FileStream, IoError> opened = FileStream::open(storePath(), "w");
    if (opened.isErr())
    {
        println("无法写入 {}", storePath());
        return;
    }
    FileStream stream = opened.unwrap();
    for (Task t in tasks)
    {
        String flag = "0";
        if (t.done)
        {
            flag = "1";
        }
        stream.write(flag + "|" + t.text + "\n");
    }
    stream.close();
}

void printTasks(List<Task> tasks)
{
    if (tasks.len() == 0)
    {
        println("（清单是空的，用 add 加一条）");
        return;
    }
    int64 i = 1;
    for (Task t in tasks)
    {
        String mark = "[ ]";
        if (t.done)
        {
            mark = "[x]";
        }
        println("{} {} {}", i, mark, t.text);
        i = i + 1;
    }
}

int64 parseIntOr(String s, int64 fallback)
{
    Result<int64, ParseError> r = std::parse::Parse::parseInt64(s);
    if (r.isErr())
    {
        return fallback;
    }
    return r.unwrap();
}

String joinFrom(List<String> args, int64 start)
{
    List<String> rest;
    for (int64 i = start; i < args.len(); i = i + 1)
    {
        rest.push(args[i]);
    }
    return std::text::Text::join(rest, " ");
}

void usage()
{
    println("用法：todo <命令> [参数]");
    println("  add <内容>    加一条待办");
    println("  list          列出全部");
    println("  done <序号>   标记完成");
    println("  remove <序号> 删除一条");
    println("  clear         清空");
}

int64 main(List<String> args)
{
    if (args.len() == 0)
    {
        usage();
        return 0;
    }

    String command = args[0];
    List<Task> tasks = loadTasks();

    if (command == "add")
    {
        String text = joinFrom(args, 1);
        if (text == "")
        {
            println("add 后面要写内容");
            return 1;
        }
        Task t;
        t.text = text;
        t.done = false;
        tasks.push(t);
        saveTasks(tasks);
        println("已添加，现在有 {} 条", tasks.len());
        return 0;
    }

    if (command == "list")
    {
        printTasks(tasks);
        return 0;
    }

    if (command == "done")
    {
        if (args.len() < 2)
        {
            println("done 后面要写序号");
            return 1;
        }
        int64 index = parseIntOr(args[1], 0);
        if (index < 1 || index > tasks.len())
        {
            println("序号超出范围");
            return 1;
        }
        Task t = tasks[index - 1];
        t.done = true;
        tasks[index - 1] = t;
        saveTasks(tasks);
        println("完成：{}", t.text);
        return 0;
    }

    if (command == "remove")
    {
        if (args.len() < 2)
        {
            println("remove 后面要写序号");
            return 1;
        }
        int64 index = parseIntOr(args[1], 0);
        if (index < 1 || index > tasks.len())
        {
            println("序号超出范围");
            return 1;
        }
        List<Task> kept;
        int64 i = 1;
        for (Task t in tasks)
        {
            if (i != index)
            {
                kept.push(t);
            }
            i = i + 1;
        }
        saveTasks(kept);
        println("已删除第 {} 条", index);
        return 0;
    }

    if (command == "clear")
    {
        List<Task> empty;
        saveTasks(empty);
        println("已清空");
        return 0;
    }

    println("未知命令：{}", command);
    usage();
    return 1;
}
\end{lstlisting}

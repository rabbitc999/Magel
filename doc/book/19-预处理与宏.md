# 第 19 章 预处理与宏

本章介绍以 `%` 和 `$` 开头的两类源码加工工具：Magel 的
**预处理**和**宏**——在代码被正式编译**之前**，先对源码做一次「文本层面」的加工。

这一章分两半：

- **预处理**（`%` 开头）：条件编译、文件包含——「这段代码要不要编进去」；
- **宏**（`$` 开头）：文本替换——「把这个缩写换成一长串代码」。

先说一句要紧的话：**这两样都是"不得已才用"的工具。** 平时用函数、泛型、常量就够了。
但读别人的代码、或者做嵌入式多平台构建，绕不开它们，所以得会认、会写。

---

## 19.1 条件编译：`%define` + `%if`

同一个程序，调试时想多打日志、发布时想去掉——这是条件编译最典型的用途：

```magel
%define DEBUG 1

int64 main() {
%if DEBUG
    println("debug on");
%else
    println("debug off");
%endif
    return 0;
}
```

```text
debug on
```

把第一行改成 `%define DEBUG 0`，同一份代码就输出另一个分支：

```magel
%define DEBUG 0

int64 main() {
%if DEBUG
    println("debug on");
%else
    println("debug off");
%endif
    return 0;
}
```

```text
debug off
```

几条要点：

- `%define` 定义**预处理符号**；
- `%if 符号` 看它的值：**非 0 走 `%if` 分支，0 走 `%else`**；
- **不活跃的分支整块丢弃**——一个字都不会编进去；
- 指令行**必须顶格**写在行首（`%` 前面不能有别的字符）；
- 被丢弃/指令占用的行**用空行占位**，所以预处理后**行号和源文件一一对应**，
  报错永远指回你真正写错的那一行。

> `%if` 后面要写**符号名**，不能写 `%if 1` 这种字面量——写了会报
> 「这里要写一个符号名」。这是它和 C 的 `#if` 最容易混的地方（见 19.6）。

## 19.2 按「有没有定义」分支：`%ifdef` / `%ifndef`

有时候你只关心「这个符号定义过没有」，不关心值：

```magel
int64 main() {
%ifdef FEATURE
    println("有 FEATURE");
%else
    println("没有 FEATURE");
%endif
    return 0;
}
```

```text
没有 FEATURE
```

- `%ifdef 符号`：**定义过**就走；
- `%ifndef 符号`：**没定义**才走（`%ifdef` 的反面）。

`%if` 和 `%ifdef` 的分工记住一句话：**`%if` 看值，`%ifdef` 看有没有。**

---

## 19.3 从命令行传开关：`-D`

开关真正好用，是**构建时**才决定——同一份源码，编出不同版本：

```sh
magel run app.mgl -D FEATURE
```

```text
有 FEATURE
```

`-D FEATURE` 等价于在文件开头写了 `%define FEATURE`。于是同一份代码：

- `magel run app.mgl` → 「没有 FEATURE」；
- `magel run app.mgl -D FEATURE` → 「有 FEATURE」。

**发布版 / 调试版、不同硬件平台，就靠这个开关切。**

---

## 19.4 `%include`：把文件原地拼进来

`%include` 在**当前文件里原地展开另一个文件**，像是把那边的文本复制过来：

<!-- no-run -->
```magel
%include "util.mgl"

int64 main() {
    println("{}", twiceValue(21));
    return 0;
}
```

如果 `util.mgl` 里定义了 `twiceValue`，这段就能跑，输出 `42`。

`%include` 和 `import`（第 18 章）解决的不是一回事：

| | `import`（模块） | `%include`（预处理） |
| --- | --- | --- |
| 层次 | 语言层 | 预处理层，早于编译 |
| 效果 | 引入模块，按裸名调函数 | **文本原地展开** |
| 同一文件重复 | 只算一次 | 默认也只一次（`%include_once` 显式表达） |
| 适用 | 正常组织代码 | 常量表、平台片段、生成代码 |

**优先用 `import`。** `%include` 是给「同一份片段要拼进很多文件」这种场景留的。

## 19.5 宏：`$macro` 文本替换

宏用 `$macro 名字(参数) … $end_macro` 定义，**调用时名字前加 `$`**：

```magel
$macro SQUARE(x)
((x) * (x))
$end_macro

int64 main() {
    println("{}", $SQUARE(5));
    println("{}", $SQUARE(2 + 3));
    return 0;
}
```

```text
25
25
```

`$SQUARE(5)` 在编译前被**文本替换**成 `((5) * (5))`；`$SQUARE(2 + 3)` 变成
`((2 + 3) * (2 + 3))`。

不带参数的叫**对象宏**，调用时也不用括号：

```magel
$macro GREETING()
"hello, magel"
$end_macro

int64 main() {
    println("{}", $GREETING);
    return 0;
}
```

```text
hello, magel
```

宏还能拼出新名字。`$concat(a, b)` 把两段拼成一个标识符：

```magel
$macro CAT(a, b)
$concat(a, b)
$end_macro

int64 main() {
    int64 $CAT(my, var) = 7;
    println("{}", myvar);
    return 0;
}
```

```text
7
```

`$CAT(my, var)` 展开成 `myvar`——**这在手写代码时基本没用**，但代码生成器特别爱用它。

### 有序多括号分组

定义端可以按任意顺序组合 `< >`、`[ ]`、`( )` 和 `{ }`，也可以重复同一种括号。调用必须照定义中的顺序写；每一组的 `..参数` 只捕获本组当前层级的内容。

<!-- verify-book -->
```magel
$macro SHOW<..Types>[..Attrs](..Args){..Body}
println("{}", $stringify(Types));
println("{}", $stringify(Attrs));
println("{}", $stringify(Args));
Body
$end_macro

$macro EMPTY()()
println("repeated groups");
$end_macro

int64 main()
{
    $SHOW<List<List<int64>>, String>[readonly](x, y){
        int64 total = 2 + 3;
        if (total > 0)
        {
            println("{}", total);
        }
    }
    $EMPTY()()
    return 0;
}
```

```text
List<List<int64>>, String
readonly
x, y
5
repeated groups
```

这里的 `readonly`、`x`、`y` 只是被捕获和字符串化的原文，不需要是有效变量。宏仍位于词法分析前，不把参数解析成 AST，也不检查参数类型。尖括号里的 `>>` 按两个闭合字符分组，不会被宏阶段当作右移运算符。

大括号参数可以跨多行。嵌套括号、字符串和注释中的逗号不会切开外层参数；不同括号组的变长捕获互相隔离。顺序、结构或绑定不匹配时报告“宏Token分组不匹配”。展开片段保留来源文件及行列映射，后续诊断仍定位原始源码。

`$macro EMPTY()()` 是两个连续空组，调用时也写 `$EMPTY()()`。既有单组对象宏 `$macro NAME()` 仍沿用 `$NAME` 的对象宏调用方式。完整说明可直接执行 `magel man macro`，也支持 `--json`。


### 重复括号：两组独立的变长参数

同一种括号可以连续出现多次。下面的定义要求调用时也提供两组小括号；`A` 只收集第一组，`B` 只收集第二组，两个尾参互不串组。

<!-- verify-book -->
```magel
$macro example(...A)(...B)
{
    print("A=[");
    $for var in A
    print("{} ", var);
    $end_for
    println("]");
    print("B=[");
    $for var in B
    print("{} ", var);
    $end_for
    println("]");
}
$end_macro

int64 main()
{
    $example(1, 2, 3, 4)(3, 2, 4, 1);
    $example(1, 2, 3, 4, 5, 6)(3, 2, 4, 1);
    return 0;
}
```

```text
A=[1 2 3 4 ]
B=[3 2 4 1 ]
A=[1 2 3 4 5 6 ]
B=[3 2 4 1 ]
```

每个 `$for` 仅遍历对应分组绑定的原始文本。即使两组都用小括号，也不会合并成一个尾参；`$example(1, 2, 3, 4, 3, 2, 4, 1)` 缺少第二组括号，会报告“宏Token分组不匹配”。这里同样可以把 `...A` / `...B` 写成 `..A` / `..B`。

### 将两组参数收集为异构列表

元素槽明确写成 `Any`，同一列表就可以保存整数、字符串等不同类型。宏仍只复制参数原文；自动装箱发生在展开后的 `push` 通过正常类型检查时。

<!-- verify-book -->
```magel
$macro example(...A)(...B)
{
    List<Any> listA;
    List<Any> listB;
    $for var in A
    listA.push(var);
    $end_for
    $for var in B
    listB.push(var);
    $end_for
    yield (listA, listB);
}
$end_macro

int64 main()
{
    auto li = $example(1, "2", 3, 4, 1, 1)(3, 2, 4, 1);
    auto listA = li.0;
    auto listB = li.1;
    Any first = listA[0];
    Any second = listA[1];
    println("A={} B={}", listA.len(), listB.len());
    println("{} {}", tryGet<int64>(&first).unwrap(), tryGet<String>(&second).unwrap());
    return 0;
}
```

```text
A=6 B=4
1 2
```

两组 `$for` 各自生成 `push`，`yield (listA, listB);` 将两个列表组成元组交给调用者。`auto li` 的具体类型是 `(List<Any>, List<Any>)`；`li.0` 与 `li.1` 是两个列表。`tryGet<T>` 按精确的装箱类型取副本，类型不匹配时返回 `None`。离开作用域自动释放列表及其元素，无须手写 `Drop`。

## 19.6 宏的第一个坑：括号要自己加

宏是**纯文本替换**，它不懂运算优先级。看这个「反面教材」：

```magel
$macro BAD_SQUARE(x)
x * x
$end_macro

int64 main() {
    println("{}", $BAD_SQUARE(2 + 3));
    return 0;
}
```

```text
11
```

`$BAD_SQUARE(2 + 3)` 被替换成 `2 + 3 * 2 + 3`——按优先级一算**是 11，不是 25**。
`*` 只管到了紧挨着的数。

**所以写宏的铁律：参数、整个宏体、都要裹上括号。** 19.5 里 `SQUARE` 写成
`((x) * (x))` 就是这个道理。对比一下：

```magel
$macro SQUARE(x)
((x) * (x))
$end_macro

int64 main() {
    int64 five = 5;
    println("{} {}", $SQUARE(five), $SQUARE(five + 1));
    return 0;
}
```

```text
25 36
```

`five + 1` 被裹进括号，先加后乘，结果才对。

## 19.7 第二个坑：`%if` 只认符号名

想按一个字面量分支？不行：

<!-- fail -->
```magel
int64 main() {
%if 1
    println("ok");
%endif
    return 0;
}
```

```text
magel：前处理：hello.mgl:2:4: error: 这里要写一个符号名 [bad-expression]
```

`%if` 后面必须是**预处理符号**（`%define` 定义过的、或者 `-D` 传进来的）。
要按数分支，先定义成符号：`%define LEVEL 1`，再 `%if LEVEL`。

`%error` 则是在**活跃分支里**主动报错——常用于「这种情况本不该编进来」：

<!-- fail -->
```magel
%define LEVEL 3

int64 main() {
%if LEVEL
%error 不该编到这里
%endif
    return 0;
}
```

```text
magel：前处理：hello.mgl:5:1: error: 不该编到这里 [error-directive]
```

配套还有 `%warning`（报警告，不中断），用法一样。

## 19.8 括号形参：每次出现都包一层括号

19.6 说宏体是文本替换，`$TIMES_TWO(1 + 2)` 会散成 `1 + 2 * 2`。
第一种挡法是**用括号标注形参**：

```magel
$macro TIMES_TWO((x))
    x * 2
$end_macro
int64 main() {
    println("{}", $TIMES_TWO(1 + 2));
    return 0;
}
```

```text
6
```

括号标注只写在 `$macro` 头这一行（`(x)`），宏体里引用形参照旧写裸名字 `x`；
效果是**这个形参每次出现**都换成 `(实参)`，于是 `(1 + 2) * 2 = 6`。

---

## 19.9 `expr` 宏：整段展开再包一层

第二种挡法是**在宏名前面写 `expr`** —— 它给整段展开结果再包一层括号：

```magel
$macro expr PLUS((a), (b))
    a + b
$end_macro
int64 main() {
    println("{}", 10 / $PLUS(2, 3));
    return 0;
}
```

```text
2
```

`10 / ((2) + (3)) = 2`；只包形参的话是 `10 / (2) + (3) = 8`。
`expr` 只写在头这一行，同时默认给全部实参加括号；`a` 与 `(a)` 完全等价，宏名还是 `PLUS`，调用处写 `$PLUS(2, 3)`；
调用点统一使用普通宏调用形式；旧的感叹号与反引号标注均已废除。

两种挡法怎么选：普通宏按需用 `(a)` 标注；整个宏作为表达式使用时声明为 `expr` 宏。

## 19.10 变长尾参 `...rest`

形参表末尾写 `...名字`，剩下的实参全归它：

```magel
$macro REPORT(...rest)
println("{} {} {}", rest);
$end_macro
int64 main() {
    $REPORT(1, 2, 3)
    return 0;
}
```

```text
1 2 3
```

`rest` 会按 `, ` 拼成**一段文本**再替换，所以在调用位置就是"一串实参"
（和 C 的 `__VA_ARGS__` 一个意思）—— 上面正好当三个实参喂给 `println`。

---

## 19.11 按实参个数重载

同一个宏名可以按**实参个数**挂多种形态：

```magel
$macro REPORT(a)
println("one {}", a);
$end_macro
$macro REPORT(a, b)
println("two {} {}", a, b);
$end_macro
int64 main() {
    $REPORT(7)
    $REPORT(1, 2)
    return 0;
}
```

```text
one 7
two 1 2
```

挑形态的顺序：**个数正好对上的固定形态 → 变长形态**。
一个都对不上会报错并把候选列出来，不会悄悄挑一个不相干的形态。

---

## 19.12 `$for`：按尾参重复一段

`$for 变量 in 尾参名 … $end_for` 把宏体里那一段按尾参逐个重复：

```magel
$macro SUM_SQUARES(...values)
int64 total = 0;
$for v in values
total = total + (v) * (v);
$end_for
println("平方和 = {}", total);
$end_macro
int64 main() {
    $SUM_SQUARES(2, 3, 4)
    return 0;
}
```

```text
平方和 = 29
```

`$for` 只能遍历**变长尾参**。每轮把循环变量整体换成该轮的实参文本，
所以 `(v) * (v)` 这种"把变量包在中间"的写法是安全的。
`$for` 的结束符是 `$end_for`、宏体的结束符是 `$end_macro` —— 两个"结束"分开写，
嵌套时不用数层数。`$for` 里还能再嵌 `$for`。

---

## 19.13 尾参逐元素加括号 `...(values)`

19.12 里靠手写 `(v)` 保平安。想让编译器代劳，就把**尾参名**放进括号，写成 `...(values)`：

```magel
$macro SUM_SQUARES(...(values))
int64 total = 0;
$for v in values
total = total + v * v;
$end_for
println("平方和 = {}", total);
$end_macro
int64 main() {
    $SUM_SQUARES(1 + 1, 2 + 1)
    return 0;
}
```

```text
平方和 = 13
```

`values` 仍按 `, ` 摊开，但**每个元素各包一层括号**，所以 `$for` 的循环变量变成 `(元素)`：
`(1+1)² + (2+1)² = 13`。不作括号标注就是 `1+1*1+1 + 2+1*2+1 = 8`。
`...` 必须放在括号外；`(...values)` 会报错。

## 19.14 `$concat`：拼出一个标识符

```magel
$macro DECLARE(prefix, suffix, value)
int64 $concat(prefix, suffix) = value;
$end_macro
int64 main() {
    $DECLARE(local, Count, 11)
    println("{}", localCount);
    return 0;
}
```

```text
11
```

`$concat(a, b)` 的两个实参**必须都是标识符**，拼出来的结果也是标识符，
而且**不重新参与宏展开**。拼出来的是普通名字，所以能和真正的函数同名共存
（宏调用必须带 `$`，裸名是普通标识符）。

> `$concat` 与 `$stringify` 都读取原始实参，不受表达式参数括号保护影响。

---

## 19.15 `$stringify`：取调用点写下的原文

```magel
$macro SOURCE(expr)
$stringify(expr)
$end_macro
int64 main() {
    println("{}", $SOURCE(1 + 2));
    return 0;
}
```

```text
1 + 2
```

结果是**字符串字面量**：实参在宏体里是形参名时取调用点的原始实参文本（不加括号），
否则就取写下的字面文本。写日志、断言信息时特别好用 —— 变量名和它的值能一起打出来。

---

## 19.16 `$replace`：一行写完的宏

`$replace` 把声明压进一行，头这一行剩下的内容就是宏体，**没有 `$end_macro`**：

```magel
$replace expr ADD((a), (b)) a + b
int64 main() {
    println("{}", $ADD(1, 3));
    return 0;
}
```

```text
4
```

它支持 `$macro` 的所有"行内"规则（参数括号、`expr`、`$concat` / `$stringify`、
`$line` / `$file` / `$module`），但**装不下 `$for` 这种块** —— 要块请用 `$macro`。
宏名和调用方式与 `$macro` 完全一样，两种声明混着写也行。

---

## 19.17 `$delete_macro`：撤掉再重新定义

同一名字、同一参数个数的宏不能重复定义。要"改"一个宏，先撤后立：

```magel
$macro REVISION()
1
$end_macro
$delete_macro REVISION
$macro REVISION()
2
$end_macro
int64 main() {
    println("{}", $REVISION);
    return 0;
}
```

```text
2
```

## 19.18 `$n` 整数编号：宏内的唯一临时名

宏是文本替换，宏体里起个临时变量很容易撞上调用点的同名变量。
`$n` 整数编号 由编译器在**每次展开时**换成一个全局唯一的名字：

```magel
$macro SWAP((a), (b))
    int64 $0 = a;
    a = b;
    b = $0;
$end_macro
int64 main() {
    int64 tmp = 111;
    int64 x = 1;
    int64 y = 2;
    $SWAP(x, y)
    println("x={} y={} tmp={}", x, y, tmp);
    return 0;
}
```

```text
x=2 y=1 tmp=111
```

宏内的临时名和调用点的 `tmp` 互不干扰。同一次展开里同一个 `$n` 处处同名；
不同展开、不同宏、嵌套调用各自独立。

编号不限于一位数字：`$10`、`$123456789012345678901234567890` 和 `$-1` 都合法。编号按十进制整数文本归一化，`$0010` 与 `$+10` 等同于 `$10`，`$-0` 等同于 `$0`；不经过宿主整数转换，因此没有 int64 上限。字符串和注释里的 `$0` 原样保留。
这是**变量级近似卫生** —— 解决的是"宏内临时变量被捕获"，
不是完整卫生宏：宏体里引用的自由名字（比如外部函数名）仍然绑到调用点。

### 用多括号宏构造 List

下面把类型放进尖括号，把元素放进中括号；宏展开成带值块，最后通过 `yield $0;` 把构造好的列表交给初始化表达式。

<!-- verify-book -->
```magel
$macro vec<T>[...list]
{
    List<T> $0;
    $for var in list
    {
        T $1 = var;
        $0.push($1);
    }
    $end_for
    yield $0;
}
$end_macro

int64 main()
{
    List<int32> myList = $vec<int32>[1, 2, 3];
    for(auto var in myList)
    {
        println("{}", var);
    }
    return 0;
}
```

```text
1
2
3
```

`T` 捕获文本 `int32`，`...list` 捕获当前中括号组的三个片段；这里也可以写成 `..list`。`$for` 逐项生成初始化与 `push` 语句，宏阶段不解析元素类型；展开后的 `T $1 = var;` 由正常类型检查验证每个元素。

`$0` 和 `$1` 是当前宏调用专属的临时名字。一次展开内所有 `$0` 都指向同一个列表；每次循环生成的 `{ ... }` 是独立作用域，因此可以重复声明同一个 `$1`。另一次调用会获得另一套名字。最后的 `break` 移交块内列表的所有权，离开作用域时仍正常清理其他局部值。

`for(auto var in myList)` 从 `List<int32>` 推断 `var` 为 `int32`，不必重复写元素类型；也可以省略 `auto`，写成 `for(var in myList)`。这里的 `auto` 不会引入动态类型或运行时类型判断。

## 19.19 `$line` / `$file` / `$module` 和 `$assert`

```magel
module demo;

$macro HERE(tag)
println("{} 在第 {} 行，模块 {}", tag, $line, $module);
$end_macro

int64 main() {
    $HERE("这里")
    return 0;
}
```

```text
这里 在第 8 行，模块 demo
```

写在宏体里时，取的是**调用点**那一行（和 C 的 `__LINE__` 一个意思），
所以基于它的报错总是指向你写宏调用的地方。`$file` / `$module` 展开成字符串字面量，
可以直接拼接或喂给 `format`；根文件没写 `module` 时 `$module` 是 `__root`。
`$assert(条件)` / `$assert(条件, "说明")` 是系统给的断言宏，用的就是这套机制。

---

### 宏内条件与局部绑定

`$if` / `$elif` / `$else` / `$end_if` 在宏展开时选择分支，`$let` 创建只属于当前宏调用的局部文本绑定。

<!-- verify-book -->
```magel
$macro expr PICK(value)
$let selected = value
$if selected > 0
selected
$else
0
$end_if
$end_macro
int64 main() {
    println("{} {}",$PICK(7),$PICK(-2));
    return 0;
}
```

```text
7 0
```

`$argc` 取得当前调用的实参数量，`$count(...)` 计数变长尾参或局部文本列表，`$typecheck(T, expr)` 将展开表达式送进指定类型检查。实参计数不匹配在展开期报错；递归最多 64 层，一次处理最多展开 100000 次。没有 `$match` 迷你 DSL，`##` 与 `#形参` 均已移除，拼接和字符串化只用 `$concat` / `$stringify`。

`$macro expr ADD(a,b)` 中的参数自动括起来，定义里的 `(a)` 可作冗余标注；普通宏仍需 `(a)` 明确标记表达式实参。调用使用普通形式 `$ADD(x+1,y*2)`，宏定义不接受反引号标注。

## 19.20 完整指令速查

| 指令 | 作用 |
| --- | --- |
| `%define 名字 [值]` / `%undefine 名字` | 定义 / 取消符号 |
| `%if` / `%elif` / `%else` / `%endif` | 按**值**条件编译 |
| `%ifdef` / `%ifndef` | 按**是否定义**条件编译 |
| `%include "路径"` | 原地展开文件（默认只一次） |
| `%error` / `%warning` | 活跃分支里报错 / 报警告 |
| `$macro N(参数) … $end_macro` | 函数式宏，调用 `$N(…)` |
| `$macro N() … $end_macro` | 对象宏，调用 `$N` |
| `$concat(a, b)` | 拼标识符 |
| `$stringify(x)` / `$line` | 把参数变成字符串 / 当前行号 |
| `$delete_macro N` | 取消宏（先撤后立，好重定义一个同名宏） |
| `` $macro N((a), (b)) `` | 显式形参括号：该形参**每次出现**都替换成 `(实参)` |
| `$macro expr N(…) … $end_macro` | 宏名前的 `expr`：**整段展开**再包一层括号 |
| `$replace N(参数) 宏体` | 单行宏，没有 `$end_macro` |
| `$macro N(...rest)` | 变长尾参；`rest` 按 `, ` 摊成一段文本 |
| `` $macro N(...(rest)) `` | 变长尾参**逐元素**加括号 |
| `$for v in rest … $end_for` | 按变长尾参重复宏体里的这一段 |
| `$concat(a, b)` | 拼标识符（两个实参都必须是标识符） |
| `$stringify(x)` | 取实参的源码文本，结果是字符串字面量 |
| `$n` 整数编号 | 宏体内的唯一临时名（每次展开换一个新名字） |
| `$line` / `$file` / `$module` | 调用点行号 / 文件名 / 模块名（宏内外都能用） |

> 字符串里的 `%` 不是指令；真想打一个百分号，写 `%%`。

## 19.21 什么时候该用，什么时候别用

**预处理和宏是"元编程的粗活"**，能不用就别用：

| 你的想法 | 更好的选择 |
| --- | --- |
| 「一段逻辑重复了」 | 写成**函数**（第 4 章） |
| 「同一段逻辑要适配多种类型」 | **泛型**（第 14 章） |
| 「想要一个常量」 | `const`（第 3 章） |
| 「给函数起个短别名」 | 想清楚——直接调原函数更清楚 |
| 「按平台/调试开关切代码」 | ✅ **`%define` + `%if`**，正解 |
| 「把常量表拼进多个文件」 | ✅ `%include`，合理 |
| 「生成一大堆重复代码」 | ✅ `$macro`，正当用途 |

宏的坏处：**它在类型系统之外**。写错了编译器不一定能帮你抓，报错也常指向展开后的乱码
（虽然 Magel 会贴心地标 `[宏 MIN]` 告诉你出错在哪个宏里）。所以能上函数就上函数。

## 19.22 小结

| 你会了 | 关键点 |
| --- | --- |
| `%define` / `-D` | 定义预处理符号；`-D` 从命令行传 |
| `%if` / `%else` / `%endif` | 按**值**分支（`%if` 后只能写符号名） |
| `%ifdef` / `%ifndef` | 按**是否定义**分支 |
| 行号 | 指令/丢弃行用空行占位，报错指回真实位置 |
| `%include` | 文本原地展开；正常组织代码请用 `import` |
| `$macro` | `$macro N(x) … $end_macro`，调用写 `$N(…)` |
| 对象宏 | `$macro N() … $end_macro`，调用写 `$N` |
| 括号铁律 | 宏体、参数都要裹括号，否则优先级出错 |
| `$concat` | 拼标识符（代码生成用） |
| 选型 | 优先函数 / 泛型 / 常量；宏留给构建开关和代码生成 |

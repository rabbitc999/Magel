# 《玩转 Magel 语言》

一本从零开始、一章只讲一件事的 Magel 入门书。

你不需要会 C，也不需要懂编译原理。这本书从头讲起，每章只解决一个问题，
代码都能直接粘下来跑。读完它，你能独立写出结构清楚、资源管得干净的 Magel 程序，
并且知道遇到问题时该去查哪一篇官方文档。

> 本书内容与 Magel 的当前[语言版本](../../VERSION)和[能力说明](../17-capabilities.md)保持同步。
> 你可以按下方目录在线阅读，也可以下载 [PDF 电子书](latex/book.pdf)，离线阅读或打印。

---

## 这本书写给谁

- 刚开始学编程，想找一门“看得清楚”的语言入门；
- 写过 C / Java / Go / Python，想快速知道 Magel 和它们哪里不一样；
- 要维护一份逻辑、同时跑在服务端和嵌入式板子上，想知道这门语言能不能扛。

如果你只是想要一份语法清单，那你该看 [语言参考](../04-language-reference.md)；
这本书的目标不一样——它想让你**读懂一门语言的设计**，而不只是记住写法。

---

## 怎么读

三条建议，按重要性排序：

1. **一定要动手。** 每章的代码都短，敲一遍的收益远大于读十遍。
   随便建一个目录，把代码存成 `x.mgl`，然后 `magel run x.mgl`。
2. **按顺序读，别跳。** 这本书是**层层递进**的：第 6 章解释为什么第 3 章的赋值
   那么“笨”，第 7 章的引用规则又是从第 6 章长出来的。跳着读，你会觉得语言在无理取闹。
3. **卡住了先看每章最后的「小结」和「下一步」。** 那里写清了哪些内容本章刻意没讲、
   以及去下一章还是去查官方文档。

书里的代码块分三类，看栅栏上的标注就知道：

| 标注 | 含义 |
| --- | --- |
| 完整的 `main` 函数 | 可以整段复制出去跑，输出的内容就写在代码下面 |
| 只有几行的片段 | 声明、表达式、语法示意，要放进程序里才能跑 |
| 命令行 | 以 `magel` 开头，直接敲 |

> Windows 上程序名是 `magel.exe`。在 Git Bash / MSYS 里写 `./magel` 能自动找到它；
> 光写 `magel` 会走 PATH 查找，可能找不到当前目录里这份。

## 和官方文档的关系

这本书**不替代**官方文档，它是官方文档的**导读**。

| 你想 | 去哪 |
| --- | --- |
| 跟着书学语言 | 就是这儿 |
| 查某个语法怎么写 | [语言参考](../04-language-reference.md) |
| 理解这些设计为什么这么做 | [核心概念](../03-core-concepts.md) |
| 5 分钟跑起来 | [快速开始](../01-quickstart.md) |
| 查某个标准库函数 | [库函数 API 参考](../library/README.md) |
| 看官方给的可运行样例 | [`example/samples/`](../../example/samples/) |

本书正文里凡是引用官方文档的地方，都给了相对链接，可以随时跳过去。

## 开始之前

- 工具链：见 [第 1 章](01-第一个程序.md)。
- 编辑器：推荐装 [`vscode/`](../../vscode/) 下的 Magel 插件，有语法高亮、
  补全、跳转与断点调试；不装也能读完整本书。
- 心里准备：第 6 到第 8 章会请你改掉一些习惯。别急着问“为什么不直接给我”，
  作者在那三章里把取舍写清楚了。

准备好了就翻到 [第 1 章](01-第一个程序.md)。

# 第 4 章 函数

第 2 章的猜数字程序全塞在 `main` 里。如果它再长三倍——比如加上「记录每次猜测」、
「算平均猜几次」——`main` 就再也读不动了。

函数就是解决这个的：**给一段代码起个名字，需要的时候叫它**。

这一章讲清楚五件事：怎么定义、怎么传参、怎么返回、怎么重载、以及怎么一次返回好几个值。

---

## 4.1 定义与调用

```magel
int64 add(int64 a, int64 b)
{
    return a + b;
}

void log(String message)
{
    println("[log] {}", message);
}

int64 main()
{
    log("start");
    println("{}", add(1, 2));
    return 0;
}
```

```text
[log] start
3
```

拆开看一个函数的脑袋：

```text
int64        add      ( int64 a , int64 b )   { ... }
 ↑            ↑         ↑
 返回类型     名字      参数表：每个参数都要写类型
```

**`void` 表示「不返回东西」。** `log` 只做事、不交值，所以返回类型是 `void`。
`void` 函数里不用写 `return`；想中途退出，写一个光秃秃的 `return;` 就行：

```magel
void trace(int64 number)
{
    if (number < 0)
    {
        return;
        // 负数不看，直接走
    }
    println("n={}", number);
}
```

**函数可以写在 `main` 前面或后面**，Magel 不要求「先声明后使用」。
这一点比 C 舒服——不用再维护一份头文件里的原型。

**函数的顺序也有讲究**，但不是给编译器的，是给读代码的人的：把「先读的放前面」。
一般先放小工具，再放用它的人，最后才是 `main`。

---

## 4.2 参数是**副本**

这是本章最重要的一条规则，也是第 6 章那条大规则的小预告：

```magel
void shout(String text)
{
    text = text + "!";
}

int64 main()
{
    String word = "hi";
    shout(word);
    println("{}", word);
    return 0;
}
```

```text
hi
```

**`shout` 里改了 `text`，`main` 里的 `word` 一点没变。**

从 C++ / Java / Python 过来的人最容易在这里栽跟头：那些语言里字符串、对象传进去
往往是「共享的引用」，函数里一改外面就变了。Magel **不是**——传进去的是**一份完整的副本**。

想真的改到外面那个，得**显式要求传引用**（`T mut&`），这是第 7 章的内容。
现在你只要记住：**函数的参数表就是「我复制这些值过来用」。**

> 那大对象传进去岂不是很贵？是的，会很贵。这正是 Magel 让你**自己决定**的地方：
> 不想复制就写 `String const&`——一次显式的选择，而不是编译器偷偷替你优化。
> 第 7 章会给出这几条写法的完整对照。

## 4.3 返回值

```magel
int64 clamp(int64 value)
{
    if (value < 0)
    {
        return 0;
    }
    return value;
}
```

**`return` 后面跟的值的类型，必须和函数声明的返回类型一致**，不允许隐式转换
（还记得第 3 章那条规矩吧）。返回 `int64` 的函数不能 `return 3.5;`。

一个函数可以有多个 `return`——只要每条路都返回了一样类型的值。上面那个 `clamp`
有两条出路，都返回 `int64`。

**如果一条路忘了返回呢？** 编译期就会报错，不会让你跑到一半发现「这个函数返回了垃圾」。

---

### 返回一个带值的控制表达式

`return` 后面既可以写普通值，也可以写块、`if`、`match` 或 `loop`。它们先给出一个结果，函数再返回这个结果。

<!-- verify-book -->
```magel
int64 fromBlock()
{
    return
    {
        int64 local = 3;
        yield local;
    };
}

int64 choose(bool first)
{
    return if (first)
    {
        yield 5;
    }
    else
    {
        yield 6;
    };
}

int64 fromMatch(int64 item)
{
    return match (item)
    {
        0 => { yield 7; }
        _ => { yield 8; }
    };
}

int64 fromLoop()
{
    return loop
    {
        yield 9;
    };
}

int64 main()
{
    println("{} {} {} {}", fromBlock(), choose(false), fromMatch(0), fromLoop());
    return 0;
}
```

```text
3 6 7 9
```

这里的 `yield value;` 给出当前值表达式的结果，不是返回函数。只有表达式完成后，外层 `return` 才返回函数。所有可能给出结果的分支必须具有完全相同的类型；不能让一支是 `int32`、另一支是 `int64`，再指望编译器自动凑成同一种类型。

在这个返回表达式内部，不能再嵌套当前函数的 `return`，也不能使用 `break level N` / `break all` 跨层跳转；会提前返回的 `?` 同样需要改成显式匹配。表达式里新定义的独立函数有自己的返回边界。只含一个结果的 `{ value }` 分支仍可沿用前面的简写。

内部拥有值变量通过 `break` 交出结果时会隐式移动，外部变量仍按值复制。移动先保存结果，再执行离开作用域的清理；不会把已经交出去的值再析构一次。引用不能因此逃出来源的生命周期。第 8 章的清理规则和第 14 章的泛型返回会继续解释这些边界。


## 4.4 重载：同名不同参

同一个名字，可以按**实参类型**挑不同的实现：

```magel
int64 add(int64 a, int64 b)
{
    return a + b;
}

float64 add(float64 a, float64 b)
{
    return a + b;
}

int64 main()
{
    println("{} {}", add(1, 2), add(1.5, 2.5));
    return 0;
}
```

```text
3 4
```

选哪个是**编译期**定下来的，看实参类型：`add(1, 2)` 两个都是 `int64`，走第一份；
`add(1.5, 2.5)` 两个都是 `float64`，走第二份。

这和第 3 章那条「没有隐式转换」是配套的：**因为不做隐式转换，重载的挑选才是准的。**
如果 `int64` 能自动变 `float64`，`add(1, 2.5)` 到底该走哪一份就得靠一套复杂的
「谁更优」规则去猜了。Magel 的选择是：**不猜，让你把类型写对。**

找不到匹配的重载时，报错会把**它拿到了什么类型**和**有哪些候选**都列出来。
比如只定义了 `int64` 的 `add`，却拿一个 `int64` 加一个 `float64` 去调：

<!-- fail -->
```magel
int64 add(int64 a, int64 b)
{
    return a + b;
}

int64 main()
{
    println("{}", add(1, 2.5));
    return 0;
}
```

```text
magel：调用 函数 add 找不到匹配的重载：(int64, float64)；没有参数类型能对上的重载（候选：add）
```

看到这种错，先看括号里**它拿到了什么类型**，再决定是改实参还是加一份重载。
（顺便：`2.5` 是 `float64`，`add(1, 2.5)` 里的 `1` 也不会被「凑」成 `float64`——
回想第 3 章：**没有隐式转换**。）

## 4.5 默认参数

参数可以带默认值，调用时从**尾部**省略：

```magel
int64 add(int64 a, int64 b = 10)
{
    return a + b;
}

int64 main()
{
    println("{} {}", add(2), add(2, 3));
    return 0;
}
```

```text
12 5
```

两条规矩：

- 带默认值的参数必须**排在后面并且连续**——不能「第 1 个有默认值、第 2 个没有」：

  ```text
  magel：函数 add 的默认参数后不能有必填参数
  ```

- 省略时只能**从尾部往前**省。`add(2)` 省掉了 `b`，没问题；`add()` 不行，因为 `a`
  没有默认值：

  ```text
  magel：调用 函数 add 找不到匹配的重载：()；没有参数类型能对上的重载（候选：add）
  ```

默认值在**每次省略该参数时重新求值**。所以别在默认值里写「记录调用次数」这种
带副作用的表达式——每次都会算一遍。

> 什么时候用默认值？**当一个参数大多数调用都会传同一个值，且传别的值不影响语义**。
> 比如 `add(a, b = 10)` 里的 `b` —— 它是「可选的微调」。反过来，
> 一个「猜数字最大值」这种参数就别给默认值，因为给了等于偷偷替调用方做了决定。

## 4.6 变长参数

最后一项参数可以写成 `T...`，表示「这里可以给任意多个」：

```magel
int64 total(int64... items)
{
    int64 sum = 0;
    for (int64 item in items)
    {
        sum = sum + item;
    }
    return sum;
}

int64 main()
{
    println("{} {}", total(1, 2, 3), total(5));
    return 0;
}
```

```text
6 5
```

`items` 在函数体里就是一个能遍历的容器。`for (int64 item in items)` 是
「把 `items` 里的东西一个个拿出来，每轮叫它 `item`」——第 5 章细讲 `for-in`。

变长参数只能放在**最后一项**，而且一个函数只能有一处。

## 4.7 一次返回多个值

Magel 的返回值可以是一个**元组**（tuple）——把几个值打包起来：

```magel
(int64, String) describe(int64 id)
{
    return(id, "player");
}

int64 main()
{
    auto info = describe(7);
    println("{} {}", info.0, info.1);
    return 0;
}
```

```text
7 player
```

- 返回类型写成 `(int64, String)`，就是「一个 `int64` 加一个 `String`」；
- `return (id, "player");` 把两个值打包成元组；
- 取的时候用 `.0` / `.1` —— **这是位置，不是名字**，从 0 开始数。

**`return` 后面的括号可以省**，`return id, "player";` 和上一种写法等价。

如果你不想用 `.0` / `.1`，可以直接**拆开接**：

```magel
(int32, String) pair(int32 key, String name)
{
    return key, name;
}

int64 main()
{
    int32 key;
    String name;
    key, name = pair((int32)7, "player");
    println("{} {}", key, name);
    return 0;
}
```

```text
7 player
```

这行 `key, name = pair(...)` 的意思是：**把右边元组按位置拆给左边的每一个目标**。
左边必须是已经声明过的变量——声明新变量请写 `auto (key, name) = pair(...);`。

> 元组还能用来交换两个变量，而且不用中间变量：
> `x, y = (y, x);` —— 右边先整个求值一次，再逐个写回去。
> 注意右边那个括号不能省，`x, y = y, x;` 会报「多目标解构赋值必须使用 `=` 和一个元组来源」。

## 4.8 入口 `main` 的两种形态

到现在为止你写的都是不带参数的版本：

<!-- no-run -->
```magel
int64 main()
{
    ...
}
```

要读命令行参数，换成另一种：

<!-- run --args Alice "two words" -->
```magel
int64 main(List<String> arguments)
{
    println("收到 {} 个参数", arguments.len());
    for (String item in arguments)
    {
        println("  {}", item);
    }
    return 0;
}
```

```text
收到 2 个参数
  Alice
  two words
```

**只有这两种入口是合法的**，别自己发明第三种。

传参的写法要注意：**直接给文件时，文件后面的都算程序参数**。

```sh
magel app.mgl Alice "two words"
```

但如果你把场景词 `run` 显式写出来，就得多一个 `--` 把「配置词」和「程序参数」隔开：

```sh
magel run app.mgl -- Alice "two words"
```

不写 `--` 的话，`Alice` 会被当成另一个源文件，报「一次只能编译一个源文件」。

## 4.9 小结

| 你会了 | 关键点 |
| --- | --- |
| 定义 | `int64 add(int64 a, int64 b) { return a + b; }` |
| 不返回值 | 返回类型写 `void`，里面可以 `return;` 提前退出 |
| 调用 | 位置实参，从左往右一一对应 |
| 参数语义 | **按值传入，形参是副本**，改形参不影响调用方 |
| 重载 | 同名不同参，编译期按实参类型选，报错会列出候选 |
| 默认参数 | `int64 b = 10`，只能从尾部连续省略 |
| 变长参数 | `int64... items`，放最后一项，用 `for-in` 遍历 |
| 多值返回 | 返回类型写元组 `(A, B)`，用 `.0` / `.1` 取或拆开接 |
| 入口 | `int64 main()` 或 `int64 main(std::lang::List<std::lang::String> arguments)` |

还有两处本章故意没讲透：

- **`static` 方法**（写在类型上、用 `Type::method()` 调）和第 2 章那个
  `Random::withSeed` —— 那是结构体的东西，第 9 章讲；
- **把函数当值传递**（`int64 fn(int64)` 类型、`fn`）—— 第 15 章讲。

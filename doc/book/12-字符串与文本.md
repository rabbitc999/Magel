# 第 12 章 字符串与文本

`String` 你从第 1 章就在用了，但一直没细讲。这一章补上——而且有个坑必须早点讲：

> **`String` 的下标和切片是按「字节」算的，不是按「字」算的。**
> 对英文没差别，对**中文会出事**。

先讲基本操作，再讲这个坑，最后是 `std::text` 里那堆好用的工具。

---

## 12.1 `String` 是什么

```magel
String name = "Magel";
```

- 双引号括起来的是 `String`；
- `String` 是 `std::lang::String` 的简写，**属于核心模块 `lang`，不用 import**；
- 里面有转义：`"\n"`（换行）、`"\t"`（制表）、`"\""`（一个双引号）、`"\\"`（一个反斜杠）。

**一个重要区别**：单引号是 `char`（**一个**字符），双引号是 `String`。这两者不能混：

```magel
char letter = 'M';
// 一个字符
String word = "Magel";
// 一串字符
```

## 12.2 拼接、下标、切片、长度

```magel
int64 main()
{
    String first = "Magel";
    String second = " 2026";
    String joined = first + second;

    println("{}", joined);
    println("len={} 首个字符={}", len(joined), joined[0]);

    println("切片 [0:5] = {}", joined[0: 5]);
    println("切片 [5:]  = {}", joined[5:]);
    return 0;
}
```

```text
Magel 2026
len=10 首个字符=M
切片 [0:5] = Magel
切片 [5:]  =  2026
```

- **`+` 拼接**两个字符串。和数字的 `+` 不是一回事——`1 + "a"` 是编译错误。
- **`s[i]` 取第 `i` 个「字符」**（先按这个理解，12.4 节纠正它）。
- **切片写 `s[from:to]`**，**左闭右开**：`joined[0:5]` 是下标 0、1、2、3、4 这五个。
- **`s[from:]`** 从 `from` 一直到结尾，`s[:to]` 从开头到 `to`。
- **`len(s)`** 是长度。

改单个字符也可以，但**要赋一个 `char` 给它**：

```magel
int64 main()
{
    String word = "hello";
    word[0] =(char)72;
    // 72 就是 'H'
    println("{}", word);
    return 0;
}
```

```text
Hello
```

**字符串是值**（第 6 章），所以赋值得到的是副本：

```text
String original = "hello";
String copy = original;
copy[0] = (char)72;      // 只改 copy
```

这一点和第 6 章讲的一模一样：`original` 还是 `hello`。

## 12.3 格式化：`format`

`println` 的 `{}` 你已经很熟了。光要字符串、不要打印，用 `format`：

```magel
int64 main()
{
    int64 count = 42;

    // {} 按实参顺序填
    println("{}", format("值={}，下一个是 {}", count, count + 1));

    // {:x} / {:X} / {:b}：整数专用的进制样式
    println("{}", format("255 的十六进制是 {:x}，二进制是 {:b}", 255, 255));

    // 浮点要写成 {索引:小数位数F}，索引从 1 数起
    println("{}", format("圆周率约 {1:2F}", 3.14159));

    return 0;
}
```

```text
值=42，下一个是 43
255 的十六进制是 ff，二进制是 11111111
圆周率约 3.14
```

占位符的要点：

- **`{}` 是位置占位符**，按实参顺序填，**类型由实参推导**，字符串 / 整数 / 浮点都能填；
- **`{:x}` / `{:X}` / `{:b}`** 把整数按十六进制 / 大写十六进制 / 二进制打印——**只有整数和 `bool`
  能用这几个样式**。写别的样式（比如 `{:5}`、`{:03}`）会直接报
  「整数和 bool 的格式仅支持 `:b`、`:x`、`:X`」；
- **浮点用 `{索引:小数位数F}`**，索引 **从 1 数起**：`{1:2F}` 表示「把第 1 个实参保留 2 位小数」；
- **补零 / 对齐**没有单独的样式，要用 `std::text::Text::padStart`（见 12.6 节）——
  想知道 `序号 007` 怎么写，翻到 12.6 节的那个例子。

> **输出函数使用 `{}` 填入参数**。字符串里的 `%d` / `%s` 只是普通文本，没有参数替换含义；要填入变量，请使用前面介绍的占位符。

**`+` 拼字符串、`format` 拼带变量的字符串、`println` 直接打印**——
三种手段各有各的位置。短的两三个用 `+`，带变量的用 `{}` 更清楚。

### 12.3.1 每个值都有 `toString()`

无参 `toString()` 返回这个值的文本，结果是独立拥有的 `String`。例如整数 `42` 得到 `"42"`，布尔值得到 `"true"` 或 `"false"`，字符串得到自身的值。结构体按声明顺序展示字段值，不加字段名或类型名前缀。

| 值的种类 | 默认表示 |
| --- | --- |
| 结构体的两个字符串字段 | `{"one", "two"}` |
| List 或数组 | `[1, "two", true]` |
| Set | `{1, 2, 3}` |
| Map | `{"count": 3, "name": "Magel"}` |
| 元组 | `(1, "two", [1, "two", true])` |

以下程序同时展示结构体、异构容器和元组。Set、Map 的顺序沿用容器的迭代顺序。

<!-- verify-book -->
```magel
struct Pair
{
    String left;
    String right;
};

int64 main()
{
    Pair pair;
    pair.left = "one";
    pair.right = "two";
    List<Any> list = {1, "two", true};
    Set<int64> set = {3, 1, 2};
    Map<String, Any> map = {"name": "Magel", "count": 3};
    auto tuple = (1, "two", list);

    println("{}", pair.toString());
    println("{}", list.toString());
    println("{}", set.toString());
    println("{}", map.toString());
    println("{}", tuple.toString());
    return 0;
}
```

```text
{"one", "two"}
[1, "two", true]
{1, 2, 3}
{"count": 3, "name": "Magel"}
(1, "two", [1, "two", true])
```

复合值里的字符串加双引号，双引号、反斜杠、换行等字符会转义；直接对字符串调用 `toString()` 不额外加引号。空 List 是 `[]`，空 Set 和 Map 是 `{}`。`Any` 展示其中实际保存的值，未装入值时显示 `Any()`。枚举按变体及载荷展示，例如 `Text("payload")`。引用、函数和不透明宿主句柄只显示 `<类型>`，不会为显示而解引用或获取所有权。

### 12.3.2 自定义方法与字符串转换共用一套协议

结构体提供 `String toString()` 后，`String text = value;` 和缺少专用显式转换时的 `cast<String>(value)` 可复用它，无须再手写一个重复的 `ImplicitConvert<String>`。反过来，已实现 `ImplicitConvert<String>` 的类型会自动获得转调该实现的无参 `toString()`。只提供 `String toString(String style)` 时，无参版本传入空样式。默认实现也可满足标准 `ToString` 和 `ImplicitConvert<String>` 泛型约束。

<!-- verify-book -->
```magel
struct Named
{
    String name;
    String toString() { return "name=" + self.name; }
};

int64 main()
{
    Named value;
    value.name = "Magel";
    String text = value;
    println("{}", text);
    println("{}", cast<String>(value));
    return 0;
}
```

```text
name=Magel
name=Magel
```

若三个入口都由用户显式定义，各自实现优先：`value.toString()` 和结构体的 `{}` 格式化使用 `toString`；隐式字符串转换使用 `implicitConvert`；`cast<String>` 优先使用 `explicitConvert`。编译器只补缺失的桥接方法，避免互相调用形成递归。

默认转换不消耗源值，也不依赖反射。临时源值在转换完成后正常清理。容器或聚合内部的自定义 `toString` 必须只读；容器遍历通过快照隔离用户回调的重入修改，错误仍保留原始诊断。默认递归展示有深度保护，重复对象路径显示 `<cycle>`。这套表示用于阅读和调试，不作为可逆序列化格式。完整验证例见仓库的 `example/samples/value_text.mgl`。

## 12.4 ⚠️ 下标是按**字节**算的

这一节是本章的重点。

```magel
int64 main()
{
    String s = "中文";
    println("len(s) = {}", len(s));
    println("第 0 个字节 = {}", (int64)s[0]);
    println("第 3 个字节 = {}", (int64)s[3]);
    return 0;
}
```

```text
len(s) = 6
第 0 个字节 = 228
第 3 个字节 = 230
```

`"中文"` 明明是**两个**字，`len` 却说 **6**。

原因是 Magel 的字符串在内存里是 **UTF-8 字节串**，而 UTF-8 里一个汉字占 **3 个字节**。
所以：

- `"中文"` = 6 个字节；
- `"Magel"` = 5 个字节（和字符数相同，因为都是 ASCII）；
- **`len`、下标、切片，都按字节算。**

`(int64)s[0]` 得到的 `228`（十六进制 `0xE4`）是「中」这个字的**第一个字节**，
`(int64)s[3]` 得到的 `230`（`0xE6`）是「文」的第一个字节。

### 取到「半个字」会怎样

`s[1]`、`s[2]` 落在「中」这个字**中间**，语言不允许你这么读：

```text
magel：运行期错误：字符串下标落在多字节字符中间（String 按字节算）
出错位置：hello.mgl:2（main）
调用栈（外 → 内）：
  main  hello.mgl:2 [thread 0 coroutine 0 ip 41]
```

切片同理：

```text
magel：运行期错误：切片端点落在多字节字符中间（String 的切片按字节算）
```

**注意这不报「越界」而是报「落在了多字节字符中间」**——说明它知道你在处理 UTF-8，
只是拒绝给你半个字。这是个明确的设计：**要么给你一个完整的字节序列边界，
要么明确拒绝，不给你一段乱码。**

### 所以中文怎么按字处理？

**别用下标切中文。** 三种办法：

1. **整个串用**：`println("{}", s)` 打印是对的——因为整串的边界永远合法；
2. **按分隔符切**：用 `std::text::Text::split(s, "，")`（12.6 节）。
   分隔符本身是完整的字符，切出来的每一段边界也合法；
3. **遍历要自己算**：想知道 UTF-8 里每个字有几个字节，看首字节的高位就行：

   | 首字节范围 | 这个字占几字节 |
   | --- | --- |
   | `0x00`–`0x7F` | 1（ASCII） |
   | `0xC0`–`0xDF` | 2 |
   | `0xE0`–`0xEF` | 3（含常见汉字） |
   | `0xF0`–`0xF7` | 4 |

   按这张表跳过**续字节**（`0x80`–`0xBF`），就能一个个字地走。

简单说：**处理中文文本，用 `std::text` 那些按字符/子串工作的函数，
不要自己拿下标去数。**

## 12.5 比较

```magel
int64 main()
{
    println("{} {} {}", "abc" == "abd", "abc" < "abd", "abc" > "abd");
    return 0;
}
```

```text
0 1 0
```

`==` / `!=` / `<` / `<=` / `>` / `>=` 都能用在字符串上。
比较用的是**字典序**（按字节比大小）。

两个实用的写法（片段，`name` / `expected` 假定已存在）：

<!-- no-run -->
```magel
if (name == "")
{
    println("名字是空的");
}
if (name != expected)
{
    println("不匹配");
}
```

**判空就用 `== ""`**，没有 `is_empty` 之类的专用函数。

## 12.6 `std::text`：文本工具箱

切分、查找、大小写、去空白这些活儿在 `std::text::Text` 里。要 `import`：

```magel
import std::text;

int64 main()
{
    String raw = "  Hello, Magel!  ";

    println("[{}]", std::text::Text::trim(raw));
    println("{} {}", std::text::Text::toUpper("abc"), std::text::Text::toLower("ABC"));
    println("{} {}", std::text::Text::find("hello", "ll"), std::text::Text::contains("hello", "lo"));
    println("{} {}", std::text::Text::startsWith("hello", "he"),
        std::text::Text::endsWith("hello", "lo"));

    List<String> parts = std::text::Text::split("a,b,c", ",");
    println("{} -> {}", parts.len(), std::text::Text::join(parts, "-"));

    println("[{}]", std::text::Text::replace("aaa", "a", "b"));
    println("[{}][{}]", std::text::Text::padStart("7", 3, (char)48),
        std::text::Text::repeat("ab", 3));
    return 0;
}
```

```text
[Hello, Magel!]
ABC abc
2 1
1 1
3 -> a-b-c
[bbb]
[007][ababab]
```

对照着记：

| 函数 | 作用 | 备注 |
| --- | --- | --- |
| `trim(s)` | 去掉两端空白 | 还有 `ltrim` / `rtrim` 只去一边 |
| `toUpper` / `toLower` | 大小写转换 | 只对 ASCII 字母有效 |
| `find(s, needle)` | 找子串位置 | 找不到返回 `-1`；`rfind` 从右找 |
| `contains(s, needle)` | 子串在不在 | 返回 `bool` |
| `startsWith` / `endsWith` | 前后缀判断 | |
| `split(s, sep)` | 按分隔符切开 | 返回 `List<String>` |
| `join(parts, sep)` | 用分隔符接起来 | |
| `replace(s, from, to)` | 替换所有出现 | |
| `padStart(s, width, fill)` | 左边补到指定宽度 | 还有 `padEnd` |
| `repeat(s, count)` | 重复 | |
| `charAt(s, i)` | 按字节取字符 | 和 `s[i]` 等价 |
| `compare(a, b)` | 比大小 | 返回整数，不用管具体值 |

> `padStart("7", 3, (char)48)` 里那个 `(char)48` 是字符 `'0'`。
> 补位字符要传 `char`，不是 `String`——这是类型严格带来的小麻烦，写一次就记住了。

## 12.7 字符串是值：别在循环里拼

`String` 是值，**每次 `+` 都在造一根新字符串**。所以这样写会很慢（片段，`lines` 假定已存在）：

<!-- no-run -->
```magel
String text = "";
for (String line in lines)
{
    text = text + line + "\n";
    // 每轮都复制一遍已经拼好的部分
}
```

数据量小的时候无所谓。上千行的时候，代价是**平方级**的。

怎么办？Magel 没有 `StringBuilder` 这种类，但有更顺手的办法：
**把要拼的东西先塞进 `List<String>`，最后 `join` 一次。**

```magel
import std::text;

int64 main()
{
    List<String> lines;
    lines.push("第一行");
    lines.push("第二行");
    lines.push("第三行");

    String text = std::text::Text::join(lines, "\n");
    println("{}", text);
    return 0;
}
```

```text
第一行
第二行
第三行
```

**一条经验**：循环里拼字符串，先攒 `List`，出循环再 `join`。

### 插值字符串

插值字符串写成 `f"..."`，只有 f 后紧跟双引号才识别为插值，单独的 f 仍是标识符。花括号里是完整表达式，每个实参按顺序求值一次，最终沿用 `format` 的语义。

<!-- verify-book -->
```magel
int64 main()
{
    int64 count = 3;
    String text = f"count={count + 1}, {f"inner={count}"}, \{literal\}";
    println("{}", text);
    return 0;
}
```

```text
count=4, inner=3, {literal}
```

`\{` 和 `\}` 输出字面大括号。嵌套插值由内到外展开；没有花括号包围的文本不求值。

### 整行输入和文件文本

`std::lang::readLine()` 读取一行，保留空格和空行，去掉 LF/CRLF；EOF 返回空串。`std::lang::readLines(int32 N)` 最多读 N 行，用 LF 连接，EOF 提前结束，不额外追加行末换行。另有 int64 重载接受普通整数实参，检查后转为 int32。N 为零时不读输入，负数或超出 int32 正范围触发错误。`String` 不能包含内嵌零字节。

<!-- no-run -->
```magel
int64 main()
{
    String name = std::lang::readLine();
    String notes = std::lang::readLines(2);
    println("name=[{}], notes=[{}]", name, notes);
    return 0;
}
```

`inputLine()` 和 `input(variable)` 按空白取项。`--input` 已按空白切分，每项供新接口视为一行；要保留真实空格和空行，使用终端或标准输入管道。

导入 `std::io` 后，`FileStream.readString(count)` 从当前游标读至多 count 个字节，`readLine()` 读一行，`readAllString(maxBytes)` 读到 EOF。三者返回 `Result<String,IoError>`；全读默认预算 16 MiB，保留文件换行字节，零字节文本报错。已有按路径的 `readAllText(path)` 继续可用。直接持有 File 句柄时有 `fileReadString`、`fileReadLine`、`fileReadAllString` 包装，错误会 panic。

完整验证程序见 [行输入](../../example/samples/std_read_lines.mgl) 与 [文件读取](../../example/samples/std_file_strings.mgl)。

## 12.8 小结

| 你会了 | 关键点 |
| --- | --- |
| 字面量 | 双引号 `"…"`；单引号是 `char` |
| 拼接 | `+`；数字和字符串不能混着拼 |
| 下标 / 切片 | `s[i]`、`s[a:b]`（左闭右开）、`s[a:]`、`s[:b]` |
| 长度 | `len(s)` |
| **按字节** | **`len` / 下标 / 切片都按字节算；中文一个字 3 字节** |
| 半个字 | 下标或切片落在多字节字符中间 → **运行期错误** |
| 格式化 | `format`：`{}` 自动填、`{:x}` 整数进制、`{1:2F}` 浮点位数 |
| 比较 | `==` `!=` `<` `>`，字典序 |
| 判空 | `s == ""` |
| 工具箱 | `import std::text;` —— `trim` `split` `join` `replace` `find` `toUpper` `padStart` … |
| 性能 | 循环里别用 `+` 拼，攒 `List` 再 `join` |

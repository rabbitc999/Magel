# 第 10 章 枚举与模式匹配

第 9 章的结构体解决的是「这些字段永远一起出现」。但有一类需求它搞不定：

> 一个值**要么是这种，要么是那种**。

「一个形状」要么是圆（带半径），要么是方形（带边长）。
「一次操作的结果」要么成功（带数据），要么失败（带原因）。

这种「多选一」的数据就是**枚举**。配合 `match`，它是 Magel 里最漂亮的一块。

---

## 10.1 定义枚举

```magel
enum Message
{
    Quit,
    Move(int32 x, int32 y),
    Text(String text)
};
```

读法是：

- `Message` 这个类型，有三种**变体**（variant）：`Quit`、`Move`、`Text`；
- `Quit` 不带数据；
- `Move` 带两个 `int32`；
- `Text` 带一个 `String`。

**变体可以带字段**，这在类型理论里叫「代数数据类型」——
但用起来没那么玄：**枚举就是「有几个可能形状，每个形状各自带自己的数据」**。

枚举声明在 `}` 处结束，尾分号可选，与 `struct` 和 `interface` 一致。

造一个值用 `类型::变体`（片段，`Message` 假定已定义）：

<!-- no-run -->
```magel
Message first = Message::Quit;
Message second = Message::Move((int32)3, (int32)7);
Message third = Message::Text("hello");
```

（`(int32)3` 那个强转是必须的——字面量默认是 `int64`，第 3 章的老规矩。）

---

## 10.2 用 `match` 处理

拿到一个枚举值，怎么知道它是哪个变体、里面的数据是什么？用 `match`：

```magel
enum Message
{
    Quit,
    Move(int32 x, int32 y),
    Text(String text)
};

void show(Message message)
{
    match (message)
    {
        Message::Quit =>
        {
            println("quit");
        }
        Message::Move(x, y) =>
        {
            println("move {} {}", x, y);
        }
        Message::Text(text) =>
        {
            println("text {}", text);
        }
    }
}

int64 main()
{
    show(Message::Quit);
    show(Message::Move((int32)3, (int32)7));
    show(Message::Text("hello"));
    return 0;
}
```

```text
quit
move 3 7
text hello
```

写法是：

```text
match (要看的东西) {
    模式 => { 该做什么 }
    模式 => { 该做什么 }
}
```

**注意三个语法细节：**

1. 被匹配的表达式要**用括号包起来**：`match (message) {`。
2. 箭头是 **`=>`**（和 C++ 的 `switch` 完全不同），每个分支的主体是**一对花括号**。
3. **`match` 后面不加分号**——它是语句，不是表达式。
   这和 `loop` 正好相反（`loop` 是表达式，语句位置要写 `};`）。
   写错了会报「期望 字符串 / 数字 / 标识符 ……，实际是 分号(;)」。

**分支里的变量是「自动绑定」的。** `Message::Move(x, y) => ...` 里写的 `x`、`y`
不是提前声明的变量，而是**当场从变体里取出来的**（片段，一条 `match` 分支）：

<!-- no-run -->
```magel
Message::Move(x, y) =>
{
    println("move {} {}", x, y);
}
```

这一句同时干了两件事：判断「是不是 `Move`」，以及「把里面那两个 `int32` 取出来叫 `x`、`y`」。

## 10.3 穷尽性：编译器帮你查漏

这是 `match` 比 `if / else` 强得多的地方。

```magel
enum Color
{
    Red, Green
};
```

<!-- fail -->
```magel
enum Color
{
    Red,
    Green
};

int64 name(Color color)
{
    match (color)
    {
        Color::Red =>
        {
            return 1;
        }
    }
    return 0;
}

int64 main()
{
    return 0;
}
```

```text
magel：enum match 必须覆盖所有变体或提供 `_` 兜底分支；缺少：Color::Green
```

**漏了一个变体是编译错误，不是运行期的意外。**

这条规则的价值在于：以后你给枚举**加一个变体**，所有没处理它的 `match`
会**立刻全部报错**。编译器会挨个指出「你还没处理新来的那个」。

这才是「用类型保护重构」——改动带来的影响，编译器替你数清楚了。
用 `if / else` 加字符串比较的写法，永远得不到这层保护。

**实在想偷懒**（比如只想处理其中一种），加一个兜底分支（`...` 是省略，不是真语法）：

<!-- no-run -->
```magel
match (color)
{
    Color::Red =>
    {
        ...
    }
    _ =>
    {
        ...
    }
    // 剩下的都到这儿
}
```

`_` 是通配符，表示「其他所有情况」。**但每次写 `_` 都是在放弃后面的检查**——
加新变体时不会再有提醒。**能列全就列全。**

## 10.4 枚举方法

枚举和结构体一样可以有方法，方法里用 `self` 指当前的枚举值：

```magel
enum Shape
{
    Circle(int64 radius),
    Square(int64 side);

    int64 area()
    {
        match (self)
        {
            Shape::Circle(radius) =>
            {
                return 3 * radius * radius;
            }
            Shape::Square(side) =>
            {
                return side * side;
            }
        }
        return 0;
    }
};

int64 main()
{
    println("{}", Shape::Circle(2).area());
    return 0;
}
```

```text
12
```

`match (self)` 就是「看看我自己是哪个变体」。
把「一个形状的面积」这件事放在形状自己身上，用起来是 `shape.area()` ——
这正是前面说的「把行为和数据放在一起」。

### 为枚举派生接口

枚举也能使用 `#derive`。相等判断先区分变体，再比较当前活动变体的载荷；哈希同时计入变体和载荷，克隆保留变体并克隆载荷。

<!-- verify-book -->
```magel
#derive(Equal, Hash, Clone)
enum BookPacket
{
    Empty,
    Text(String text)
}

int64 main()
{
    BookPacket first = BookPacket::Text("value");
    BookPacket second = first.clone();
    assert(!(first == BookPacket::Empty));
    println("{} {}", first == second, first.hash(first) == second.hash(second));
    return 0;
}
```

```text
1 1
```

每个变体的载荷都必须满足所请求的接口；不能因为某个变体暂时没有在程序里构造，就跳过检查。与结构体一样，禁止派生 Drop 或 Closeable。包含无对应接口的结构体载荷时，应先为那个结构体实现或派生接口。


## 10.5 不止能匹配枚举：标量也支持

`match` 也能直接匹配整数、浮点、`bool`，用**常量**或**区间**：

```magel
int64 grade(int64 score)
{
    match (score)
    {
        100 =>
        {
            return 3;
        }
        [90, 99] =>
        {
            return 2;
        }
        [60, 89] =>
        {
            return 1;
        }
        _ =>
        {
            return 0;
        }
    }
    return 0;
}

int64 main()
{
    println("{} {} {} {}", grade(100), grade(95), grade(60), grade(59));
    return 0;
}
```

```text
3 2 1 0
```

区间仅支持两种写法：**左闭右开 `[a, b)` 与闭区间 `[a, b]`**。

| 写法 | 含义 |
| --- | --- |
| `[a, b)` | `a <= x < b` |
| `[a, b]` | `a <= x <= b` |

> **一个限制**：标量分支只接受**常量或区间**。写变量、函数调用或者别的表达式
> 会报「match 分支必须是整数 / 浮点 / bool 常量或区间模式」。
> 想按「算出来的值」分支，就老老实实用 `if / elif`。

**这时候 `_` 就是必需的**——标量有无穷多取值，不可能列全。

---

### 区间重叠的警告

整数区间与区间、单值与区间的静态重叠会产生 `MGL1601` 警告，程序仍可编译。编译器按开闭端点和完整的 int64/uint64 精度判断相交，不会把警告改成类型错误，也不会重排分支；运行时仍按原顺序和守卫选择。重复的无守卫单值模式则沿用错误规则。命令行、JSON 与编辑器使用同一警告级别。

## 10.6 守卫：先绑定，再加条件

有时候光看「是哪个变体」不够，还要看「里面的值满足什么条件」。
在模式后面加 `if`：

```magel
enum Choice
{
    Value(String text)
};

int64 kind(Choice choice)
{
    match (choice)
    {
        Choice::Value(text) if text == "good" =>
        {
            return 1;
        }
        Choice::Value(text) =>
        {
            return 0;
        }
    }
    return -1;
}

int64 main()
{
    println("{} {}", kind(Choice::Value("good")), kind(Choice::Value("bad")));
    return 0;
}
```

```text
1 0
```

`Choice::Value(text) if text == "good"` 的意思是：**先确认是 `Value` 并取出 `text`，
再判断 `text` 是不是 `"good"`**。两个条件都满足才进这个分支。

注意第二条 `Choice::Value(text) => ...` 不能省——`match` 还是要覆盖所有可能性，
守卫不算「覆盖」。

> 守卫的关键字是 **`if`**。你在一些资料里可能看到写成 `when` 的版本——
> 那份写法在当前工具链上是不认的（会报「期望 条件(if)」）。记住 `if` 就好。

---

## 10.7 什么时候用 `match`，什么时候用 `if`

| 场景 | 用什么 |
| --- | --- |
| 判断「一个值属于哪种形状」 | **`match`** —— 变体全列出来，编译器查漏 |
| 一个数落在哪个区间 | **`match`** —— 比一串 `if / elif` 清楚 |
| 复杂条件（多个变量、算出来的值） | `if / elif / else` |
| 只有两个分支的简单判断 | `if / else` —— 别为了用 `match` 而用 |

一条经验：**当「分支条件是某个值的形状/范围」时用 `match`；
当「分支条件是几个东西的组合判断」时用 `if`。**

### `match` 表达式

可以直接把匹配结果用于声明、赋值或调用。所有分支必须产生同类型值；枚举仍要求穷尽，守卫不算覆盖。

<!-- verify-book -->
```magel
enum Packet
{
    Data(String text), Empty
};
int64 main()
{
    Packet packet = Packet::Data("original");
    String label = match (packet)
    {
        Packet::Data(text) =>
        {
            text = "copy";
            yield text;
        }
        Packet::Empty =>
        {
            "empty"
        }
    };
    String original = match (packet)
    {
        Packet::Data(text) =>
        {
            text
        }
        Packet::Empty =>
        {
            "empty"
        }
    };
    println("{} {}", label, original);
    return 0;
}
```

```text
copy original
```

表达式匹配的载荷绑定是值副本，修改副本不修改被匹配对象。单个结果写 `{ value }`，多语句块写 `yield value;`。外层声明或赋值仍需要分号。语句位置也支持 `match (...) { ... };`；语句也允许省略末尾分号。

## 10.8 小结

| 你会了 | 关键点 |
| --- | --- |
| 定义枚举 | `enum X { A, B(int64 v) }` —— 结尾分号可选 |
| 造值 | `X::A`、`X::B(3)` |
| `match` | 可作语句或表达式；表达式分支给出同类型值，外层声明仍加分号 |
| 自动绑定 | `X::B(v) => ...` 里的 `v` 是当场取出来的 |
| 穷尽性 | 漏变体是**编译错误**；`_` 兜底但会放弃检查 |
| 标量匹配 | 常量与区间：`100`、`[90, 99]`、`[a, b)` |
| 守卫 | `模式 if 条件 => { ... }` |
| 方法 | 枚举也能有方法，里面用 `match (self)` |

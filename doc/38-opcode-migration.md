# 38 Opcode 与标准库类型迁移记录

> 状态：迁移已完成。本页保留 0.21.0 及更早阶段确认的语义、约定与阶段结果；
> 文中“当时”“尚未”均指记录当时的状态，当前能力以[能力与边界](17-capabilities.md)
> 和 [CHANGELOG](../CHANGELOG.md) 为准。

## 38.1 迁移做了什么

迁移把内建在 VM 里的 String、BigInteger、BigDecimal、File、Process、List、Map、Set
依次改成 `opcode` 声明加胶水宿主记录：VM 只保留通用句柄、存活管理与不透明记录协议，
记录布局、比较、哈希与克隆回调归 `source/glue` 与标准库胶水。

迁移完成后 `ObjectKind` 只剩 `NativeRecord`、`Obj`、`Arena`、`Closure` 四种；
前端不再为这些类型保留专门的 `Kind`，公开类型以 `std::lang` 中的 `opcode` 声明为准，
`String`、`BigInteger`、`BigDecimal`、`File`、`Process` 均不再是特殊种类，
也不存在 `string` 类型别名。

## 38.2 已验证的语义：数组与字符串

- 字符串字面量是带长度头的 UTF-8 字节串，**不附加终止零字节**：`"hello"` 5 字节、
  `"你好"` 6 字节。相同内容的字面量合并为同一份只读数据，运行时复制出的 String 各自独立。
- `T[] s` 按值传参并复制数组，元素沿用各自的值语义；`T[] &` 与 `T[] const&` 是只读借用，
  不复制、编译期禁止写入；`T[] mut&` 是可变借用，修改作用于来源数组。
  该规则适用于全部元素类型，不采用 `T mut[]` 写法。
- 不提供解引用运算符：数组引用通过 `s[i]`、`s = value` 直接访问。
- `char[]` 隐式转换为 `String` 走复制，避免引入借用字符串的生命周期分支。
- Set、Map、List 的迭代顺序不作保证，胶水迭代路径不做排序。

## 38.3 opcode 声明约定

- 声明体绑定 `new = 创建函数`、`drop = 销毁函数`、`copy = 复制函数`。
  默认可复制的 opcode 必须提供 `copy`，语言层复制调用该函数取得独立记录，
  禁止只复制内部指针；不可复制类型省略 `copy` 并写 `#NonCopyable`。
- `#NonCopyable` 在编译期拒绝复制初始化、赋值、按值传参与按值返回，`move` 照旧转移所有权。
  这条检查与“实现 `Closeable` 的 struct 自动不可复制”是同一条路径，见
  [声明糖](28-declaration-sugars.md#closeable-与运算符推导开关)。
- opcode 是内部保存不透明句柄的特殊结构体，可声明普通字段、实例方法与静态方法。
  普通字段由语言保存、复制和销毁，不描述宿主对象的内存布局；struct 可包含多个 opcode 成员。
- `self.opcode` 只在声明模块内可读，创建后只读；普通赋值、复合赋值与取得可写引用都会被拒绝。
- 反射沿用 `@Reflect` 暴露规则，可读取 opcode 对象及其公开字段，内部句柄不进入字段表；
  LSP 同样隐藏胶水实现细节。
- ABI 与 C++ 胶水共用同一套声明和复制 / 移动限制：宿主对象要么提供复制函数，
  要么显式 `#NonCopyable`，不能退回整数别名绕过所有权规则。
- `File`、`Process` 使用 `#NonCopyable`，包装函数通过 `const&` 借用；`Process` 是公开名称，
  `proc` 只是内部简称。

## 38.5 迁移期发现、现已修复的旧问题

- 固定数组 `int64 second[2] = first;` 曾让两者共用存储（别名），现按值独立复制。
- 可变数组引用整体替换曾出现调用方越界读取，现按“先物化新数组、再释放旧元素与旧块”顺序处理，支持自赋值。
- 数组引用文法落地前，`T[] &` 让五条旧类型拼写错误用例的期望 token 多出 `[`，已同步期望文件。
- 字节输出旧重载依赖隐式共享数组，已改为显式 `uint8[] mut&`，容量不足仍返回 `false`。
- `ElementBytes` 曾对标量一律返回 8、`lowering.cpp` 多处固定步长 8，随 u8 布局一并改正。
- Windows 构建曾动态依赖 `libgcc`、`libstdc++`、`libwinpthread`，而 VSIX 只复制 EXE；
  工具链改为静态链接运行库，主程序只导入 `KERNEL32`、`msvcrt`、`WINHTTP`。
- 源码行号夹具曾使用已删除的 `##` 宏语法，改为单行 `$concat`，保留宏定义总行数与调用点断言。
- opcode 大数返回值的 `println`、循环 `format`、弃用返回值与 `opcode` 字段复制 / 移动 / 反射调用
  曾各自存在回归，现已并入固定快照专项。
